# FulfillCore 0.7.8.38

Накопительное точечное обновление поверх FulfillCore. Архив уже содержит изменения версий 0.7.8.31–0.7.8.37, поэтому устанавливать пропущенные архивы отдельно не требуется.

## Что исправлено

- Действующая упаковка больше не получает окончательную ошибку после первого пустого ответа WB на запрос этикетки.
- Автоматическая и ручная печать используют один и тот же ограниченный повторный запрос: до четырёх попыток с короткими паузами.
- Одноэлементный ответ WB без поля `orderId` больше не отбрасывается, так как запрос относится ровно к одному заказу.
- Заказы со статусом FulfillCore `PACKED` сохраняют кнопку «Этикетка WB», даже если локально сохранённый `supplierStatus` ещё не обновился.
- Отменённые заказы явно блокируются перед получением и печатью этикетки.
- Логика сканирования товара, передачи ЧЗ, упаковки, статусов и защиты от повторной автопечати не изменена.

## Фильтр заказов по бренду

- Под вкладками статусов добавлен выпадающий фильтр «Бренд».
- Бренд выбирается из готового списка, вводить название вручную не нужно.
- Можно отметить один или несколько брендов.
- Фильтр применяется сервером ко всей базе заказов текущего физического склада и склада WB, а не только к текущей странице.
- Выбор работает во вкладках «Новые», «На сборке», «Упакованные», «Доставляются», «Полученные», «Отменённые» и «Все».
- Счётчики статусов пересчитываются с учётом выбранных брендов.
- Выбор сохраняется отдельно для физического склада; несуществующие на новом складе бренды снимаются после загрузки его списка.

Список брендов строится из сохранённых заказов и импортированных карточек WB. Миграция базы данных не требуется.

## Установка

```bash
cd /opt/fulfillcore

mkdir -p backup_before_0.7.8.38
cp -a app backup_before_0.7.8.38/

unzip -o /root/FulfillCore_0.7.8.38_WB_Label_Retry_Brand_Multiselect_CUMULATIVE_FIX.zip -d /opt/fulfillcore

docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  restart api
```

Проверка:

```bash
sleep 10

docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  exec api python -c "from app.main import app; print(app.version)"
```

Ожидаемая версия: `0.7.8.38`.

После установки на каждом рабочем компьютере нажмите `Ctrl+F5`.

## Быстрая проверка

1. Откройте действующий упакованный заказ, на котором ранее появлялось сообщение «WB не вернул этикетку заказа».
2. Нажмите «Этикетка WB». FulfillCore сам выполнит короткие повторные запросы и поставит одну этикетку в очередь Print Agent.
3. Откройте по очереди «Новые», «Упакованные» и «Все».
4. В фильтре «Бренд» отметьте один бренд, затем добавьте второй.
5. Убедитесь, что заказы и счётчики меняются, а выбранные галочки сохраняются между вкладками.

# FulfillCore 0.7.8.16 — точечный FIX автоматической этикетки WB

Изменено только то, что относится к автоматической печати после сканирования ЧЗ.

- Ручная кнопка «Этикетка WB» не переделывалась.
- После принятия ЧЗ автоматическая печать берёт свежую копию этикетки WB после короткого окна стабилизации (~350 мс), чтобы не печатать ранний/нестабильный растр, который мог растягиваться на две физические этикетки.
- Та же защита работает для старого браузерного клиента, если он ещё вызывает прямую печать из scan-chz.
- Для сканеров без Enter задержка автосрабатывания поля ЧЗ уменьшена с 650 мс до 180 мс.
- ЧЗ, статусы, поставки, приёмка, Print Agent и геометрия рабочей ручной этикетки не менялись.

Установка поверх 0.7.8.15.

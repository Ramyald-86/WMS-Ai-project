# FulfillCore 0.7.8.48

Накопительное обновление поверх 0.7.8.47.

## Исправлено

- ШК поставки печатается, пока поставка остаётся открытой.
- Печать не вызывает закрытие поставки, перевод в доставку или изменение статусов заказов.
- Для открытой поставки FulfillCore локально формирует QR со значением её ID `WB-GI-…`.
- Для закрытой поставки сначала используется официальный QR WB; при временной ошибке WB доступна безопасная локальная копия.
- Кнопка `QR` переименована в понятную `ШК поставки`.
- В режиме Print Agent один ШК поставки сразу уходит на выбранную станцию печати.
- В браузерном режиме формируется PDF 58×40 мм.
- ШК коробов открытой поставки использует тот же безопасный локальный QR и больше не получает ошибку `Поставка не привязана к доставке`.
- Сохранена печать до 1000 этикеток коробов из версии 0.7.8.47.

## Важно

Официальный API Wildberries выдаёт QR-картинку поставки только после перевода в доставку. Для открытой поставки FulfillCore не вызывает этот метод и не закрывает поставку: он кодирует в QR документированное значение самого ID поставки.

## Проверка после установки

1. Откройте активную поставку WB.
2. Нажмите `ШК поставки`.
3. Убедитесь, что этикетка ушла в Print Agent или открылась в PDF — в зависимости от настроек печати.
4. Обновите список поставок: поставка должна остаться актуальной, а заказы — в прежних статусах.
5. Нажмите `ШК коробов`, укажите нужное число копий и проверьте печать без ошибки API 400.

# FulfillCore 0.7.8.41

Накопительное обновление: содержит все исправления до версии 0.7.8.40 включительно. Пропущенные обновления отдельно устанавливать не нужно.

## Пустые ячейки и короба

- Пустой короб можно удалить после вопроса «Вы уверены?».
- Пустую ячейку или палету можно удалить после такого же подтверждения.
- В списках появились галочки и массовое удаление.
- Занятые товаром адреса и короба не удаляются; при массовой операции они пропускаются с указанием количества пропущенных объектов.
- Удаление реализовано как архивирование. Объект исчезает из рабочих списков, но остаётся доступен старым операциям, поэтому история не ломается.
- Если позднее создать адрес с прежним кодом, архивный адрес безопасно активируется повторно.

## Приёмка без лишнего короба

- Ручная приёмка всегда добавляет товар прямо в выбранную ячейку.
- Отдельный короб при этом не создаётся. В остатках место отображается как `Ячейка 1-3-16`.
- Физические короба по-прежнему можно использовать в палетной приёмке и перемещать между адресами.
- В ручной приёмке остался один выбор назначения:
  - только склад FulfillCore;
  - склад FulfillCore и сразу WB FBS.
- Старые дублирующие кнопки отправки WB скрыты. Очередь Excel- и палетной приёмки отправляется из единого блока на главной странице «Приёмка».
- При выборе WB локальная операция сохраняется первой. Если WB временно недоступен, товар остаётся на складе, а изменение попадает в очередь повторной отправки.

## Отмена ошибочной приёмки

- В разделе «Операции» у приёмок появилась кнопка «Отменить приёмку».
- Палетную приёмку можно отметить как ошибочную из списка или карточки.
- Программа создаёт обратную корректировку, показывает изменение `было → стало` и сохраняет исходную операцию со статусом «Отменена».
- Отмена блокируется, если принятого количества уже нет на складе, например товар успели отгрузить.
- Перед отменой можно отдельно выбрать пересчёт WB FBS до текущего локального остатка.
- Палетная приёмка отменяется целиком: частичная отмена документа не допускается.

## Остатки WB FBS

- В таблице и карточке остатка отображается состояние публикации FBS.
- Для товара без подтверждённой отправки из этой версии показана кнопка «Разместить».
- После успешной отправки отображается «Размещён на FBS» и опубликованное количество.
- Если локальный остаток изменился, программа показывает переход старого количества в новое и кнопку «Обновить».
- Публикация устанавливает на WB точный текущий остаток FulfillCore, поэтому повторный запрос не задваивает количество.
- Старые размещения, сделанные до установки 0.7.8.41 или вручную в кабинете WB, автоматически не считаются подтверждёнными. Один раз нажмите «Разместить», чтобы FulfillCore записал актуальное состояние.

## Новая этикетка адреса 58×40

- Крупный код адреса расположен по центру, например `1-3-16`.
- Штрихкод расположен внизу.
- Значение штрихкода напечатано под полосами.
- Квадрат и подписи в правом верхнем углу удалены.
- Формат работает для одной ячейки, выбранных адресов, диапазона и печати всех адресов.

## Предыдущие исправления сохранены

- Восстановление печати этикетки WB для упакованного заказа.
- Защита упакованного заказа от ошибочного возврата в «На сборке».
- Быстрая обработка ЧЗ и защита от повторной автопечати.
- Раздельные настройки складов WB для физических складов.
- Фильтр по брендам с выбором одного или нескольких значений.
- Сборочные листы по всем заказам статуса без ограничения 500 строк текущей страницы и без обязательного перевода новых заказов в «На сборке».

## Установка

```bash
cd /opt/fulfillcore

mkdir -p backup_before_0.7.8.41
cp -a app backup_before_0.7.8.41/

unzip -o /root/FulfillCore_0.7.8.41_Receiving_FBS_Empty_Archive_Label_CUMULATIVE_FIX.zip -d /opt/fulfillcore

docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  restart api
```

Проверка версии:

```bash
sleep 10

docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  exec api python -c "from app.main import app; print(app.version)"
```

Ожидаемая версия: `0.7.8.41`.

После установки нажмите `Ctrl+F5` на каждом рабочем компьютере.

## Короткая проверка

1. Создайте пустую тестовую ячейку и пустой короб, удалите их по одному и массово.
2. Убедитесь, что занятый короб и ячейка с товаром удалить нельзя.
3. Примите товар прямо в ячейку с вариантами «только склад» и «склад + WB FBS».
4. Откройте «Остатки», проверьте пометку FBS и кнопку «Разместить».
5. Отмените тестовую приёмку через «Операции» и проверьте обратную корректировку.
6. Распечатайте этикетку адреса `1-3-16`: крупный адрес должен быть по центру, штрихкод — внизу.

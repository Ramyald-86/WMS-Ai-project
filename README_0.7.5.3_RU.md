# FulfillCore 0.7.5.3 — Physical Departure Status Fix

Критическая логика очереди FBS:

- `Новый` = заказ физически ещё не уехал и не переведён в работу внутри FulfillCore.
- `На сборке` = только действие внутри FulfillCore / сформированный сборочный лист.
- `Упаковано` = товар отсканирован в FulfillCore + есть ЧЗ + этикетка.
- `Доставляется` = WB вернул статус, подтверждающий физическое движение после склада: передан/отправлен перевозчику, в пути, готов к выдаче, доставка перенесена, возврат и эквивалентные транспортные статусы.
- `Получен` = `sold`.
- `Отменён` = отменённые WB-статусы.

Важно: `supplierStatus=confirm/complete`, принадлежность к поставке, закрытая поставка, ЧЗ и WB-этикетка сами по себе НЕ переводят заказ в `Доставляется`. Если транспортного статуса WB нет, заказ остаётся `Новый` (если его не начали/упаковали внутри FulfillCore).

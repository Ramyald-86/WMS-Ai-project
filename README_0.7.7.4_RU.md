# FulfillCore 0.7.7.4 — WB CHZ Confirm + Idempotent Sync

Изменения поверх 0.7.7.3:

- Исправлен WB 409 Processing при ЧЗ: перед SGTIN заказ переводится в supplierStatus=confirm только если это реально нужно.
- Для уже confirm-заказов сохранён быстрый путь: один запрос записи ЧЗ без лишних meta/status-проверок.
- Для new-заказов FulfillCore создаёт/переиспользует служебную активную поставку и переводит заказ в confirm, затем сразу отправляет исходный DataMatrix.
- Локальный статус «На сборке» по-прежнему управляется FulfillCore и не вычисляется из WB confirm.
- Фоновый reconcile стал идемпотентным: повторный ЧЗ не валит всю синхронизацию с uq_marketplace_order_chz / 500.
- Один ЧЗ по-прежнему нельзя привязать к разным заказам.
- Остальные функции 0.7.7.3/0.7.7.2 сохранены.

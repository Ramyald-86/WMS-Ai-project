# FulfillCore 0.7.7.5 — интерфейс карточек WB

Изменения поверх 0.7.7.4:

- Исправлена сломанная сетка карточек WB: карточки больше не сжимаются в узкие колонки и не вылезают друг на друга.
- Панель импорта сделана компактной (220–270 px), чтобы основная ширина экрана оставалась каталогу.
- Каталог адаптивный: на широком экране показывает несколько карточек в ряд, на узком — перестраивается без горизонтального развала.
- Фото приведены к стабильному размеру 96×128, длинные названия/артикулы/бренды переносятся внутри карточки.
- Поиск и кнопка обновления остаются сверху каталога.
- Логика ЧЗ, WB FBS, палет, приёмки и остальные изменения 0.7.7.4 не менялись.

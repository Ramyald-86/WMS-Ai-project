FulfillCore 0.8.1

Точечный фикс WB сборки/упаковки:
- виртуальная ячейка ПРИЕМКА больше не исключается из доступного товара полностью;
- реальные ячейки/короба всегда имеют приоритет;
- если в реальных местах нет СВОБОДНОЙ единицы, FulfillCore может взять свободную единицу из ПРИЕМКА;
- резерв другого заказа учитывается: уже зарезервированную единицу взять нельзя;
- остальные системные зоны по-прежнему запрещены;
- существующая логика WB/ЧЗ/печати/Commercial не переписывалась.

Алгоритм:
1. свободный остаток в реальных адресах;
2. если его нет — свободный остаток ПРИЕМКА;
3. если всё зарезервировано/нет товара — НЕ ХВАТАЕТ.

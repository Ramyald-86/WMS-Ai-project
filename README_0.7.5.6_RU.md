# FulfillCore 0.7.5.6 — CHZ auto-confirm fix

Исправлено прикрепление ЧЗ после внутреннего перевода заказа «На сборку».

Раньше FulfillCore требовал, чтобы локально сохранённый supplierStatus уже был `confirm`. Из-за этого заказ мог быть «На сборке» внутри FulfillCore, но сканирование ЧЗ блокировалось.

Теперь при сканировании ЧЗ FulfillCore:
1. обновляет фактический статус конкретного заказа WB;
2. если заказ внутри FulfillCore находится «На сборке», но WB ещё не `confirm`, автоматически создаёт служебную поставку WB и добавляет туда только этот заказ;
3. после перехода WB в `confirm` сразу отправляет ЧЗ;
4. уехавшие, полученные и отменённые заказы не переводятся обратно в confirm.

Это не меняет правило интерфейса: «На сборке» по-прежнему определяется только действиями внутри FulfillCore, а не входящим статусом WB.

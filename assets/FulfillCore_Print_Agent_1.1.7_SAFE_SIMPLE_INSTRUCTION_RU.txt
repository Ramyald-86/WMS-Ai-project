FulfillCore Print Agent 1.1.7 SAFE SIMPLE

Основа: рабочий Print Agent 1.1.7 (DIRECT TSPL + защита от повторной печати).

ВАЖНО: эта версия специально НЕ создаёт Windows-службы, Scheduled Tasks и watchdog.
Она не меняет системные параметры Windows. Автозапуск — только обычный ярлык в папке Startup текущего пользователя.

Установка:
1. Подключите Xprinter и убедитесь, что тестовая страница Windows печатается.
2. В FulfillCore откройте Настройки печати, выберите рабочее место PACK-XX и нажмите Показать токен.
3. Полностью распакуйте ZIP.
4. Запустите INSTALL.bat.
5. Обычно адрес сервера просто оставьте Enter.
6. Введите PACK-XX, выберите принтер, вставьте токен.
7. Дождитесь INSTALL OK.

После INSTALL OK ничего вручную запускать не нужно.
Файлы агента хранятся в %LOCALAPPDATA%\FulfillCore\PrintAgent.

CHECK_AGENT.bat — проверка процесса.
STOP_AGENT.bat — остановка.
UNINSTALL.bat — безопасное удаление агента.

PNG/WB этикетки печатаются напрямую в Xprinter через TSPL. SumatraPDF не требуется для обычных WB PNG-этикеток.

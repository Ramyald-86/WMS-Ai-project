# FulfillCore 0.7.9.30 — массовое управление остатками + отмена

- Галочки в разделе «Остатки».
- Массовое оприходование выбранных товаров на WB FBS по текущему локальному остатку.
- Массовое удаление выбранных локальных остатков.
- Кнопка «Удалить ВСЕ остатки» с обязательным вводом подтверждения `УДАЛИТЬ ВСЕ`.
- Отмена последней массовой операции: локальное удаление возвращает товар в исходные ячейки/короба; массовая публикация WB возвращает предварительно считанные остатки WB.
- Все массовые операции записываются в `fc_inventory_bulk_actions`; повторная отмена одной и той же операции запрещена.
- Рабочая логика ЧЗ, упаковки, приёмки и сборочных листов не переписывалась.

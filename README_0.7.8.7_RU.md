# FulfillCore 0.7.8.7 — Xprinter white background + WB supplies 500 fix

## Что исправлено

1. Серверная часть совместима с Print Agent 1.1.4, где исправлена полярность RAW TSPL для XP-420B: этикетка остаётся белой, чёрными печатаются только текст, QR/DataMatrix и штрихкоды.
2. Исправлено сопоставление старых сборочных листов с поставками WB: numeric order ID теперь сравнивается с `external_order_num`. Ошибочная/старая запись в сборочном листе больше не должна валить список поставок в HTTP 500.
3. Фоновое обновление списка поставок больше не показывает пользователю бессмысленный красный `Internal Server Error`. Ошибка остаётся в console для диагностики; при ручном обновлении показывается сообщение `Поставки WB: ...`.

## Установка
Распаковать поверх `/opt/fulfillcore` и перезапустить `api` по обычной hotpatch-схеме.

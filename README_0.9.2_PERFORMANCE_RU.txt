FulfillCore 0.9.2 Performance Hotfix

1. Строгий подбор WB ШК/размера из 0.9.1 сохранен.
2. Убрана N+1 нагрузка: строгая привязка SKU выполняется пакетно для всего списка заказов.
3. Сборочный лист больше не делает несколько SQL-запросов на каждый заказ только ради проверки ШК/размера.
4. Вкладка Остатки сразу показывает локальный физический остаток FulfillCore.
5. Карточки WB и статус FBS догружаются поверх уже показанных остатков и не держат экран пустым.
6. Каталог WB на первом проходе ограничен 5000 строк (текущий масштаб склада существенно меньше этого).
7. Повторное открытие Остатков в том же клиенте/складе в течение 60 секунд использует уже загруженный каталог.
8. Исправление Print Agent /result -> 200 OK включено, чтобы обновление не вернуло старую проблему 401.

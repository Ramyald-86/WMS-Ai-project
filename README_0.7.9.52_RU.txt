FulfillCore 0.7.9.52

- Добавлен список последних массовых Excel-приёмок.
- Для каждой активной приёмки есть отдельная кнопка «Отменить приёмку».
- Отмена выполняется по batch_id и не затрагивает другие приёмки.
- Старые приёмки, созданные версиями с одной операцией на строку, также группируются по batch_id.
- Если товар уже перемещён, отмена снимает нужное количество из текущих мест хранения.
- Если часть товара уже отгружена и остатка не хватает, отмена блокируется — склад не уходит в минус.

# FulfillCore 0.7.9.22

Точечное исправление формирования сборочного листа WB.

## Исправлено

- Сборочный лист больше не блокируется собственным резервом позиции при списании товара с исходной ячейки.
- Перед штатным списанием резерв текущего заказа переводится во временное состояние `CONSUMING`, которое глобальная защита остатков не считает чужим активным резервом.
- После успешного списания резерв переводится в `CONSUMED` как и раньше.
- Если свободного остатка действительно не хватает, заказ остаётся в сборочном листе с пометкой `НЕ ХВАТАЕТ`, без ячейки/короба.
- Логика ЧЗ, печати, упаковки и размещения из 0.7.9.21 не переписывалась.

python3 tools/smoke_check_0_7_9_22.py

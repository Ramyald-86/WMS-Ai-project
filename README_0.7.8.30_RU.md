# FulfillCore 0.7.8.30 — сборочный лист, ячейки и палеты

Точечный патч поверх версии `0.7.8.29`. Логика ЧЗ, упаковки, статусов заказов и Print Agent не изменялась.

## Что изменено

### Сборочный лист WB

1. Первый столбец переименован в «Ячейка / палета».
2. В верхней части указывается уникальный номер листа вида `FC-WB-XXXXXXXX`.
3. Удалён последний столбец «Заказы WB / статус».
4. Добавлен узкий столбец `✓`, куда сборщик ставит галочку или `+` после сборки позиции.
5. Добавлен столбец «Под 0».
6. «ПОД 0 — ЗАБРАТЬ КОРОБ» появляется только тогда, когда выбранный сборочный лист забирает всё содержимое физического короба по всем товарам.
7. Ячейки, палеты, короба, артикулы и штрихкоды сохраняются текстом и не превращаются в экспоненциальный формат Excel.

### Раздел «Ячейки / палеты»

1. При создании сначала выбирается тип: «Стеллаж с ячейками» или «Палетное хранение».
2. Для стеллажа указываются проход, номер/название стеллажа, количество этажей и количество ячеек на каждом этаже.
3. Например, 6 этажей и 23 ячейки создают 138 адресов со штрихкодами.
4. Формат адреса: `ПРОХОД-СТЕЛЛАЖ-ЭТАЖ-ЯЧЕЙКА`, например `1-14-06-13`.
5. Для палеты указываются проход и номер палеты. Формат: `1-PAL-007`.
6. В палетном режиме есть кнопка «Пропустить этот номер».
7. Любую пустую пользовательскую ячейку или палету можно удалить.
8. Адрес с товаром, привязанным коробом или системный адрес удалить нельзя.

## Установка

### 1. Скачайте архив

`FulfillCore_0.7.8.30_Picking_Locations_Pallets.zip`

### 2. Передайте архив на сервер и подключитесь

Откройте PowerShell:

```powershell
scp "$env:USERPROFILE\Downloads\FulfillCore_0.7.8.30_Picking_Locations_Pallets.zip" root@5.129.203.223:/root/
ssh root@5.129.203.223
```

### 3. Сделайте резервную копию

```bash
cd /opt/fulfillcore

mkdir -p backup_0.7.8.29_before_0.7.8.30/app/routers
mkdir -p backup_0.7.8.29_before_0.7.8.30/app/services
mkdir -p backup_0.7.8.29_before_0.7.8.30/app/static

cp app/main.py backup_0.7.8.29_before_0.7.8.30/app/main.py
cp app/routers/marketplaces.py backup_0.7.8.29_before_0.7.8.30/app/routers/marketplaces.py
cp app/services/picking_lists.py backup_0.7.8.29_before_0.7.8.30/app/services/picking_lists.py
cp app/static/app.js backup_0.7.8.29_before_0.7.8.30/app/static/app.js
```

### 4. Распакуйте обновление

```bash
unzip -o /root/FulfillCore_0.7.8.30_Picking_Locations_Pallets.zip -d /opt/fulfillcore
```

### 5. Перезапустите API

```bash
docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  restart api
```

### 6. Проверьте версию

```bash
sleep 10

curl -s https://5-129-203-223.nip.io/health
```

Ожидаемая версия: `0.7.8.30`.

## Проверка после установки

1. Откройте «Ячейки / палеты».
2. Создайте тестовый стеллаж на 2 этажа и 3 ячейки — должно появиться 6 адресов.
3. Создайте тестовую палету и проверьте кнопку «Пропустить этот номер».
4. Удалите одну пустую тестовую ячейку.
5. Сформируйте сборочный лист WB.
6. Проверьте номер листа, столбцы «Ячейка / палета», «Под 0» и `✓`.

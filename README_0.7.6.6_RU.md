# FulfillCore 0.7.6.6

Точечное исправление интерфейса.

- Исправлено открытие карточки заказа WB по клику на номер: в HTML возвращено модальное окно `wbOrderModal`, которое уже ожидал JavaScript. Ошибка `Cannot set properties of null (setting innerHTML)` устранена.
- Текущая страница FulfillCore сохраняется в браузере. После F5/Ctrl+F5 пользователь остаётся на той же странице, а не возвращается на Главную.
- На странице Wildberries FBS также сохраняется выбранная статусная вкладка (Все / Новые / На сборке / и т.д.).
- Сохранены все изменения 0.7.6.0–0.7.6.5: приёмка, отложенная отправка на WB, ЧЗ, фильтры, 50/100/200/500, верхний скролл, время заказа на WB, панель складов.

# FulfillCore 0.7.8.52

Точечное исправление размещения остатка WB FBS.

## Исправлено

Если карточка товара WB уже импортирована в FulfillCore и точный ШК принадлежит выбранному клиенту, но локальная строка SKU для этого ШК ещё не была создана, кнопка «Разместить» больше не возвращает ложную ошибку «Товар с таким ШК не найден у выбранного клиента». FulfillCore создаёт недостающую локальную SKU-привязку из уже импортированной карточки WB и продолжает штатную публикацию остатка.

Проверка остаётся строго в рамках выбранного клиента: товар другого клиента автоматически не подставляется.

Остальные рабочие функции версии 0.7.8.51 не изменялись.

# FulfillCore 0.7.8.28 — упаковка и автопечать для закрытой поставки

Точечный патч поверх 0.7.8.27.

## Что исправлено

1. FulfillCore по-прежнему максимально пытается присвоить ЧЗ через WB.
2. Если WB отказывает только потому, что заказ находится в закрытой поставке и не разрешён для повторной отгрузки, складской процесс больше не останавливается.
3. Такой заказ переводится в «Упаковано» сразу после сканирования ЧЗ.
4. Этикетка WB автоматически отправляется на печать.
5. Красное уведомление о закрытой поставке не показывается упаковщику.
6. ЧЗ остаётся сохранённым за заказом, а FulfillCore периодически повторяет проверку возможности передачи.
7. Ошибка формата, дубль ЧЗ и другие реальные ошибки маркировки по-прежнему блокируют упаковку и показываются оператору.

После перезапуска ожидаемая версия: `0.7.8.28`.

# FulfillCore 0.7.6.2 — CHZ Exact Transfer

Точечный патч упаковки WB. Остальная логика 0.7.6.0/0.7.6.1 не менялась.

## Что изменено
- Убрано синхронное ожидание, пока WB вернёт только что записанный ЧЗ обратно через meta API.
- ЧЗ отправляется в WB один раз, ровно той строкой, которую отдал сканер.
- ASCII GS (0x1D) сохраняется; пробелы/сегменты кода не пересобираются.
- Удаляется только префикс сканера `]d2` и завершающие CR/LF.
- Если PUT WB вернул ошибку, заказ остаётся «На сборке» и локально ЧЗ не считается принятым.
- Если PUT успешен, ЧЗ сразу фиксируется локально, а фоновая синхронизация позже сверит его с WB без задержки упаковщика.
- Автоотправка DataMatrix ждёт 650 мс тишины; Enter от сканера отправляет сразу. Это защищает от отправки обрезанного кода при короткой паузе внутри сканирования.

# FulfillCore 0.7.9.34

Точечный hotfix печати WB поставки A4.

- Исправлен Internal Server Error при открытии A4.
- Исправлен вызов локального реестра поставок: используется client_id + cabinet_name + supply_id.
- Открытая поставка по-прежнему печатается без закрытия и без Print Agent.
- A4 открывается в текущей вкладке, поэтому разрешение всплывающих окон не требуется.
- Остальная логика FulfillCore не изменялась.

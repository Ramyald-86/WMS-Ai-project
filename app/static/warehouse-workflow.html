Для всей приёмки нажмите «Создать сборку» в её карточке. Для выборочной сборки загрузите Excel в «Складских заданиях».

Сборщик проходит всю секцию по ряду 1, затем по ряду 2. В каждом ряду — палеты по порядку; сторона палеты вмещает до 8 коробов. На ТСД видны секция, ряд, адрес, короб и товар. Физический остаток списывается после проверки и закрытия администратором. Товар, занятый сборкой, недоступен для перевода в FBS.

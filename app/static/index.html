ЕДИНОЕ ХРАНЕНИЕ

Все короба и занятые ячейки

Для хранения считаются активные физические короба с товаром и ячейки/палеты, где товар лежит напрямую без короба. Такая занятая ячейка считается как 1 коробо-место. Транзит считается отдельно, неразобранные ПВЗ-короба без ШК — ручным счётчиком.

КОРОБА БЕЗ ШК

Неразобранные короба ПВЗ

Это отдельный счётчик хранения. Он не создаёт товарные остатки. Пока короб не разобран, уменьшаем количество вручную.

ПОИСК

Фильтр хранения

Пустые, архивные, брак и FBO в автоматический счёт хранения не входят. Один физический короб считается один раз, даже если внутри есть и MAIN, и FBS.

ТАРИФЫ КЛИЕНТА

Применить тариф к категориям

Тариф действует для выбранного клиента на всех его складах. Выберите одну или несколько категорий во всплывающем окне.

Категории Категории не выбраны

Хранение: общий тариф за одно коробо-место в сутки. Разделение стоимости хранения по товарным категориям в текущем расчёте не используется.

Отдельный тариф категории имеет приоритет над общим. Отчёт и история рассчитываются по действующим тарифам — это не зафиксированные счета.

ПЕЧАТЬ

Калибровка этикеток

Основной режим — Print Agent 1.1.8 STABLE на ядре 1.1.7. Этикетка строится сразу в 203 DPI (464×320 точек для 58×40 мм) и отправляется напрямую в Xprinter. PDF, поля Windows, масштаб браузера и автоповорот драйвера в этой цепочке не участвуют.

СПОСОБ ПЕЧАТИ

Print Agent / браузер

Этот выбор используется для печати WB и других складских этикеток, которые обращаются к общим настройкам печати. Для стабильной работы используйте Print Agent; браузер оставлен как резерв.
ТОВАРНАЯ ЭТИКЕТКА

ШК товара

Товарная этикетка всегда формируется строго 58×40 мм. Размер рабочего места и настройки бумаги Windows больше не могут изменить её на PACK-станции. Масштаб и сдвиги остаются только для тонкой калибровки содержимого внутри одной этикетки.
ЭТИКЕТКА WB

Стикер заказа

WB-стикер приводится к точным 464×320 точкам с жёсткими чёрно-белыми границами штрихкодов. Для реальной печати используйте Print Agent.
Как калиброватьСначала нажмите «По умолчанию 58×40» и тестируйте через Print Agent. В норме ничего подгонять не нужно. X/Y оставлены только для механического смещения конкретного принтера. Браузерную печать используйте только как резерв — браузер может уменьшать этикетку.

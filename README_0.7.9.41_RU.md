# FulfillCore 0.7.9.42

Точечный фикс структурной Excel-приёмки и удаления остатков.

- Внизу предпросмотра структурной приёмки добавлена большая кнопка «Оприходовать / Добавить на остатки».
- Наличие одной ошибочной строки больше не блокирует весь файл.
- Все корректные строки проводятся на локальные остатки; строки с ошибками остаются помечены и не проводятся.
- После проведения интерфейс показывает количество фактически оприходованного товара и число пропущенных строк.
- Массовое удаление локального товара получило резервное сопоставление по нормализованному ШК, если старый SKU хранится в другом текстовом формате.
- WB FBS, ЧЗ, упаковка и другие рабочие модули не переписывались.

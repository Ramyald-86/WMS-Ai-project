# FulfillCore 0.7.6.3 — staged receiving → WB FBS

Изменена только логика приёмки:

- Ручная и массовая приёмка сначала меняют **только локальный остаток FulfillCore**.
- Wildberries при самой приёмке больше не обновляется.
- На страницах ручной и массовой приёмки появилась отдельная кнопка **«Отправить приёмку на WB FBS»**.
- До отправки изменения на WB сохраняются как очередь в браузере текущего рабочего места.
- Ручной режим `Добавить` при отправке прибавляет количество к текущему WB-остатку.
- Ручной режим `Изменить` при отправке устанавливает WB-остаток в указанное значение.
- Массовая приёмка всегда отправляется как `Добавить`.
- Если часть SKU WB не принял, успешные строки удаляются из очереди, ошибочные остаются для повторной отправки.

Это позволяет сначала проверить фактическую приёмку и размещение на складе, а уже затем отдельным подтверждённым действием обновить FBS-остатки WB.

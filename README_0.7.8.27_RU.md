# FulfillCore 0.7.8.27 — единая поставка ЧЗ и восстановление автопечати

Точечный патч поверх 0.7.8.26. Остатки, сборочные листы, размеры этикеток и остальные рабочие модули не изменялись.

## Что исправлено

1. FulfillCore переиспользует существующую открытую служебную поставку ЧЗ после перезапуска API, вместо создания новой для каждого сеанса.
2. Для новых поставок используется постоянное имя по складу и типу груза.
3. Если запрос передачи ЧЗ успешно принят WB, ожидание фоновой проверки больше не блокирует упаковку.
4. Заказ переходит в «Упаковано», и автоматическая печать этикетки запускается сразу после успешной отправки ЧЗ.
5. Красное уведомление об обычном ожидании проверки WB больше не показывается.
6. Реальный отказ WB или ошибка кода остаются видимыми и останавливают печать, чтобы не упаковать товар с неотправленным ЧЗ.
7. Фоновая синхронизация продолжает проверять окончательное решение WB.

## Важно о старых поставках

Патч прекращает создание лишних поставок. Уже созданные старые открытые поставки автоматически не удаляются и не закрываются, потому что в них могут находиться заказы.

После перезапуска ожидаемая версия: `0.7.8.27`.

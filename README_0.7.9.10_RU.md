# FulfillCore 0.7.9.10 — быстрый CHZ → WB-этикетка

Точечная оптимизация горячего пути упаковки. Бизнес-логика ЧЗ, резервов, отмен и списания остатков не изменена.

Что исправлено:
- автоматическая печать после успешного ЧЗ больше не запускает длинный общий recovery-цикл этикетки WB;
- для auto-after-CHZ добавлен отдельный быстрый путь: короткое settle-окно и ограниченные повторы без лишнего запроса статуса WB;
- максимальные локальные паузы одного auto-fetch снижены примерно с 1.7–2.0 с плюс status-refresh до 0.48 с;
- если WB ещё не успел спроецировать этикетку, браузер автоматически делает два коротких повтора, не заставляя упаковщика нажимать кнопку вручную;
- отменённый заказ по-прежнему проходит точную проверку WB и освобождает ЧЗ только при подтверждённой отмене;
- ручная печать «Этикетка WB» оставлена на консервативном recovery-пути — надёжность ручного восстановления не снижена;
- сканер освобождается сразу после ответа scan-chz, как в 0.7.9.3;
- добавлен Print Agent 1.2.1: опрос очереди по умолчанию каждые 250 мс вместо 1 секунды, защита от дублей сохранена.

Важно:
- время самой передачи/подтверждения ЧЗ зависит от WB API и намеренно не «ускоряется» за счёт пропуска проверок;
- серверная оптимизация работает и со старым Print Agent. Обновление агента до 1.2.1 уменьшает ещё до ~0.75 с ожидания между постановкой задания и его получением агентом.

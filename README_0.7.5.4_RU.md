# FulfillCore 0.7.5.4 — WB status routing fix

Исправление критичной очереди FBS.

Главное изменение:
- `wbStatus=sorted` теперь считается фактическим выездом со склада и переводится в `Доставляется`.
- `accepted_by_carrier`, `sent_to_carrier`, `postponed_delivery`, `ready_for_pickup` и транспортные/возвратные алиасы также остаются `Доставляется`.
- `sold` -> `Получен`.
- отменённые статусы -> `Отменён`.
- `waiting`, а также `supplierStatus=confirm/complete` без транспортного `wbStatus` не убирают заказ из рабочей очереди. Такой заказ остаётся `Новый`, если FulfillCore сам не перевёл его в `На сборке`/`Упаковано`.
- `На сборке` и `Упаковано` по-прежнему определяются только действиями FulfillCore.

Таким образом закрытая поставка WB, автоматически присвоенная этикетка или `complete` сами по себе не скрывают физически неуехавший товар, но реальный статус `sorted` и последующие этапы доставки больше не попадают в `Новые`.

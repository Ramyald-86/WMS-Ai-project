# FulfillCore 0.7.7.2

- Добавлено удаление палетной приёмки с обязательным подтверждением.
- Если в приёмку уже загружен товар, требуется второе подтверждение; удаляется структура приёмки, но складские остатки не откатываются.
- Добавлено удаление палеты до загрузки товарной раскладки; вместе с палетой удаляются её отсканированные короба после подтверждения.
- Короба в структуре приёмки теперь показываются вертикальным нумерованным списком, по одной строке на короб.
- У каждого пустого короба остаётся отдельная кнопка удаления.
- Все функции 0.7.7.1 сохранены.

Правило интерфейса: для новых сущностей, которые пользователь может создать/добавить вручную, предусматриваем обратное действие удаления. Для важных/необратимых действий используем явное подтверждение «Вы уверены?».

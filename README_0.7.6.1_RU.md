# FulfillCore 0.7.6.1 — CHZ Verified Write

Точечный патч упаковки WB. Остальная логика 0.7.6.0 не менялась.

- Перед записью ЧЗ FulfillCore проверяет, нет ли уже кода маркировки у заказа в WB.
- Если в WB уже есть другой ЧЗ, новый код не перезаписывается и упаковка останавливается.
- После отправки ЧЗ FulfillCore повторно читает метаданные конкретного заказа WB и ждёт подтверждения именно того же кода.
- Статус «Упаковано» и получение/печать этикетки разрешены только после подтверждения ЧЗ со стороны WB.
- Если WB не подтвердил запись, заказ остаётся «На сборке», локально неподтверждённый ЧЗ не сохраняется.
- После ошибки поле ЧЗ очищается и возвращает фокус для повторного сканирования.
- Автосрабатывание DataMatrix увеличено до 300 мс тишины, чтобы не отправлять обрезанный код при паузе сканера.

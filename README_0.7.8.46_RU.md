# FulfillCore 0.7.8.46

Накопительное обновление: содержит все изменения версий до `0.7.8.45` включительно. Отдельно устанавливать предыдущие архивы не требуется.

## Автоматическое сканирование ручной приёмки

- Оператору не нужно нажимать Enter.
- После завершения ввода ШК сканером программа автоматически добавляет 1 штуку в черновик.
- Поле ШК сразу очищается и остаётся активным для следующего товара.
- Быстрые последовательные сканы обрабатываются по очереди и не теряются.
- Если сканер сам отправляет Enter после ШК, товар всё равно добавляется только один раз.
- Повторный скан того же ШК увеличивает количество в существующей строке.
- Количество можно вручную изменить непосредственно в черновике.
- Сканирование не меняет остатки: проведение выполняется только кнопкой `Добавить всё на остатки`.

## История приёмок

- История по умолчанию показывает отдельную карточку для каждой проведённой приёмки.
- На карточке видны дата, время, название, сотрудник, количество товара, число позиций и адресов.
- Поле `Поставка / комментарий` переименовано в `Название приёмки`.
- Кнопка `Открыть приёмку` показывает полный состав: товар, ШК, количество, ячейку или короб и изменение остатка `было → стало`.
- Отдельный блок суммирует, сколько товара было размещено в каждый адрес.
- Возможность отменить ошибочную приёмку сохранена.
- Перемещения, отгрузки и корректировки остаются доступны через фильтр операций.

## Установка

Распакуйте архив поверх `/opt/fulfillcore`, затем перезапустите контейнер API. Миграция базы данных не требуется. После перезапуска версия API должна быть `0.7.8.46`; на всех рабочих компьютерах нужно нажать `Ctrl+F5`.

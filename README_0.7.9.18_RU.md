# FulfillCore 0.7.9.18

- Сборочный лист больше не блокируется, если товара нет на локальном остатке. Строка остаётся в Excel без ячейки/короба; статус можно перевести в «На сборке», но складской остаток не трогается.
- Индикатор заполнения перенесён из упаковки в «Адресное хранение». На карточке каждой ячейки/палеты показывается оценочный объём относительно стандартного короба WB 60×40×40 (96 л), а также приблизительный вес.
- Если у части товара нет габаритов WB, это явно показывается и не мешает работе.
- Упаковочный индикатор 0.7.9.17 удалён: заполненность теперь относится именно к физическому хранению.
- Логика 0.7.9.15 не используется.

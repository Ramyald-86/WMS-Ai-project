# FulfillCore 0.7.9.29 — углублённая диагностика задержек ЧЗ/WB

Версия продолжает 0.7.9.28 и не меняет штатную бизнес-логику упаковки/ЧЗ.

Добавлено:
- `trace_id` для каждого сканирования ЧЗ;
- отдельный лог медленного этапа `set_sgtin`, если он занял 2 секунды и более;
- расширенная строка `FC_CHZ_TIMING` с детализацией `db_precheck`, `local_save`, `wb_total`, `wb_set_sgtin`, `wb_confirm`, `wb_status`, `wb_meta`, `wb_reshipment`, `finalize`;
- скользящая статистика последних 100 запросов WB: среднее, p50, p95, максимум, количество запросов более 2 и 5 секунд;
- `FC_WB_TRACE_SLOW` позволяет сразу увидеть конкретный заказ и этап, на котором возник длинный ответ.

Диагностика не выполняет дополнительных запросов к WB и не добавляет искусственную задержку к упаковке.

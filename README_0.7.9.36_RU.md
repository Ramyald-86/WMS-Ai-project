# FulfillCore 0.7.9.42 — WB FBS chrtId stock sync

Точечное исправление публикации остатков Wildberries FBS.

## Причина
Текущая ветка FulfillCore отправляла и читала остатки через устаревшее поле `sku`/`skus`.
WB перевёл seller-stock API на `chrtId` конкретного размера. HTTP 204 больше не считаем
доказательством изменения остатка.

## Что изменено
- точный ШК сначала сопоставляется с размером карточки WB и его `chrtId`;
- PUT `/api/v3/stocks/{warehouseId}` отправляет `chrtId + amount`;
- POST проверки использует `chrtIds`;
- после PUT FulfillCore обязательно читает остаток обратно и сравнивает с отправленным;
- при несовпадении выполняется ограниченный повтор и затем показывается точная ошибка;
- массовая публикация и отмена массовой публикации также переведены на chrtId;
- клиент и физический склад остаются строго изолированы;
- складская приёмка, упаковка, ЧЗ и печать не переписывались.

## Для уже размещённых товаров с FBS=0
После установки выделите нужные позиции в Остатках и нажмите «Обновить выбранные на WB FBS».
Новая схема перепубликует фактический локальный остаток через chrtId и проверит ответ WB.

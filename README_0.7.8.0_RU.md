# FulfillCore 0.7.8.0 — Picking Excel Local Only

Исправлена кнопка «На сборку · Excel» в Wildberries FBS.

- Формирование сборочного листа больше не создаёт поставку WB и не добавляет заказы в поставку WB.
- Кнопка работает как локальная операция FulfillCore: формирует XLSX и переводит выбранные NEW-заказы в локальный статус PICKING.
- Статус заказа и поставки в Wildberries при выгрузке Excel не изменяются.
- Уже существующий ID поставки WB может попадать в файл только как справочная информация.
- Устранена ошибка WB API 409, возникавшая при попытке добавить в новую поставку заказы, которые WB уже обработал/отменил/закрепил за другой поставкой или другой WMS.

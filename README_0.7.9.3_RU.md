# FulfillCore 0.7.9.3 — ускорение сканирования упаковки

Точечная оптимизация горячего пути WB FBS без изменения складской бизнес-логики.

Что изменено:
- ШК товара: сервер сначала ищет заказы по уже привязанному локальному SKU и не перебирает всю очередь `PICKING`; для старых/непривязанных заказов сохранён прежний полный fallback-поиск.
- Ответ после ШК стал компактным: не загружаются карточка товара и другие поля, которые экран упаковки между ШК и ЧЗ не использует.
- USB-HID burst распознаётся автоматически: быстрый ШК ждёт около 85 мс после последнего символа, быстрый DataMatrix — около 220 мс. Медленные сканеры сохраняют прежний безопасный адаптивный тайм-аут.
- Enter и Tab от сканера отправляют ШК/ЧЗ немедленно.
- После успешного ответа `scan-chz` поле следующего ШК освобождается сразу. Получение/постановка WB-этикетки в Print Agent и полное обновление таблицы заказов идут в фоне и больше не блокируют следующий товар.
- Фоновая печать сериализована: быстрый упаковщик не создаёт параллельный шквал запросов этикеток.

Не изменено:
- проверка ЧЗ в WB остаётся синхронной до решения endpoint `scan-chz`; ускорение не достигается ценой упаковки заведомо отклонённого кода;
- резервы 0.7.9.1, правило отмены PACKED 0.7.9.2, Print Agent, остатки и статусы не переписаны.

# FulfillCore 0.7.6.7 — отмена после сборки → БЕЗ-АДРЕСА

- Если заказ уже вошёл в сборочный лист FulfillCore (`PICKING`/`PACKED`) и затем WB отменил его, 1 шт. больше не возвращается автоматически в исходную ячейку/короб.
- Остаток переносится из адреса, указанного в последнем сборочном листе, в системную ячейку `БЕЗ-АДРЕСА`.
- После этого товар размещается обычным перемещением/размещением в новую фактическую ячейку.
- Для заказов, которые просто вручную перевели «На сборку», но сборочного листа/резерва не было, остаток не трогается.
- Перенос идемпотентный: повторные синхронизации статуса WB не двигают одну и ту же единицу повторно.
- Остальные изменения 0.7.6.0–0.7.6.6 сохранены.

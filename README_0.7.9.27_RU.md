# FulfillCore 0.7.9.27 — массовая приёмка: удаление + выборочная отправка WB FBS

Версия продолжает 0.7.9.26.

Добавлено:
- каждая новая массовая Excel-приёмка получает batch-id; после импорта появляется кнопка «Удалить эту массовую приёмку»;
- удаление делает обратную складскую корректировку одной командой для всего batch, история исходной приёмки сохраняется;
- в массовой загрузке добавлена таблица неотправленных остатков WB FBS с чекбоксами;
- для каждой позиции видно отдельно фактический остаток FulfillCore и опубликованный остаток WB FBS;
- можно отметить только нужные позиции и нажать «Отправить выбранные на WB FBS»;
- есть «Выбрать все» и «Убрать выбранные из очереди» (последнее не меняет склад и WB);
- после отправки/удаления данные склада и FBS обновляются;
- рабочая упаковка/ЧЗ/печать не изменялись.

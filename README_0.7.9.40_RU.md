# FulfillCore 0.7.9.42

Критический hotfix безопасности остатков.

- Если выбран режим «FulfillCore + WB FBS», локальный остаток больше не меняется до подтверждения WB.
- Сначала рассчитывается будущий абсолютный остаток, затем WB должен подтвердить именно это количество.
- Только после подтверждения WB проводится локальная складская операция.
- Если WB вернул ошибку, FulfillCore остаётся без изменений.
- Если WB подтвердил, но локальная операция неожиданно не прошла, система пытается автоматически вернуть WB к прежнему количеству.
- Проверка склада WB всегда идёт напрямую через GET /api/v3/warehouses; WBClient.warehouses() больше не вызывается.
- Интерфейс уточняет, что WB FBS — синхронизация количества, а не физический перенос товара со склада.

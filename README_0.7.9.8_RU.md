# FulfillCore 0.7.9.8

Точечное исправление видимости поставок WB по выбранному seller-складу.

Что изменено:
- раздел «Поставки WB» теперь показывает поставки только того склада WB, который выбран в выпадающем списке над заказами;
- если склад WB не выбран, список поставок пуст и интерфейс просит выбрать склад;
- выбранный `wb_warehouse_id` передаётся на сервер при каждом обновлении поставок, включая фоновое обновление на нескольких компьютерах;
- сервер применяет строгий фильтр: поставки другого WB-склада и старые записи с неизвестным складом не попадают в выбранный склад;
- пустая поставка, созданная из FulfillCore, сразу сохраняется с выбранным WB-складом и поэтому видна только в нём;
- переключение склада WB сразу очищает старый список и загружает поставки нового выбранного склада;
- центральный PostgreSQL-реестр, многокомпьютерная синхронизация, создание, добавление заказов и закрытие поставок из 0.7.9.7 сохранены;
- упаковка, ЧЗ, резервы, остатки, приёмка, адресное хранение и печать не изменялись.

Логика интерфейса:
`выбранный физический склад FulfillCore + выбранный кабинет WB + выбранный склад WB = один строгий список поставок`.

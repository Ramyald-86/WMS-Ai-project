# FulfillCore 0.7.9.42

- WB-карточка больше не блокирует физическую структурную приёмку: если ШК не найден в кеше WB, строка становится предупреждением и всё равно садится на локальный склад FulfillCore.
- Добавлена кнопка «Excel: неподгруженные» в каждой структурной приёмке.
- Лист «Адресное хранение» содержит строки, которые не попали на локальный склад, и пригоден для повторной загрузки после исправления.
- Лист «Не на WB FBS» содержит позиции, у которых WB FBS меньше локального остатка, нет карточки WB или есть ошибка публикации.
- Лист «Сводка» показывает количество пропущенных строк/штук и текущую разницу FulfillCore ↔ WB FBS.
- Рабочие складские модули, упаковка и ЧЗ не переписывались.

# FulfillCore 0.7.8.2 — расширенная этикетка товара и карточка WB

- Этикетка товара 58×40 мм стала информационной: название, артикул продавца, размер, бренд, цвет, состав, страна производства и ШК.
- Печатаются только реально полученные из WB поля; пустые данные не выводятся.
- Состав и остальные характеристики Content API теперь видны в карточке товара FulfillCore.
- В карточке отображается полный список характеристик, которые WB вернул для товара.
- Формат применяется и к печати товарной этикетки из заказа через Print Agent.
- Совместимо с быстрым hotpatch-режимом (`./app:/app/app`).

# FulfillCore 0.7.9.9 — гибкая ручная структурная приёмка

## Что добавлено

- Старые режимы приёмки сохранены. В ручной приёмке доступен новый гибкий контекст хранения.
- Любая часть структуры необязательна: `Секция → Проход → Палета → Короб → Товар`. Можно использовать только короб, секцию+короб, палету+короб и другие сочетания.
- Текущий короб выбирается один раз; после этого товары сканируются подряд в него до смены короба/места.
- Короб можно открыть или создать сканированием существующего QR/штрихкода.
- Короб можно создать по введённому названию. В этом случае FulfillCore создаёт стабильный внутренний QR `FCBOX-...`, который не зависит от дальнейшего переименования короба.
- Для нового именованного короба QR можно автоматически отправить в Print Agent либо распечатать вручную.
- Секция, проход и палета создаются автоматически только если оператор их указал. Неиспользуемые уровни не создаются.
- В черновике приёмки видно полное место каждой строки: секция/проход/палета/короб.
- Сборочный лист уже умеет выводить только реально используемые складские уровни, поэтому новая приёмка автоматически попадает в эту схему.
- Заполненный существующий короб нельзя тихо перенести при приёмке в другое место: для этого остаётся штатный раздел «Перемещение». Это защищает остатки и историю.
- Старый ручной режим «обычная ячейка» доступен переключателем и не удалён.

## Без изменений

WB/Ozon, упаковка, ЧЗ, поставки, резервирование, Excel-приёмка, палетная приёмка и Print Agent не переписывались.

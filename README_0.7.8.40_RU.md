# FulfillCore 0.7.8.40

Накопительное точечное обновление. Архив содержит предыдущие исправления до версии 0.7.8.39 включительно, поэтому пропущенные версии отдельно устанавливать не требуется.

## Сборочные листы без ограничения одной страницей

- Сборочный лист можно создать из всех заказов вкладки «Новые».
- Можно создать лист из всех заказов вкладки «На сборке».
- На вкладке «Все» можно включить одновременно все новые и все заказы на сборке.
- Ограничение 500 строк текущей страницы больше не определяет состав файла: сервер сам выбирает полный набор заказов нужного статуса.
- Выбранный физический склад, склад WB и фильтры по бренду, наличию ЧЗ и этикетке сохраняются.
- Большой список загружает SKU, остатки и карточки пакетно, без отдельного запроса к базе на каждый заказ.

## Статус меняется только после вопроса

При создании листа с новыми заказами FulfillCore спрашивает:

`Перевести новые заказы из этого сборочного листа в «На сборке»?`

- `ОК` — Excel скачивается, новые заказы переводятся в «На сборке» только внутри FulfillCore.
- `Отмена` — Excel скачивается для просмотра, статусы заказов вообще не меняются.

Если лист создаётся только из заказов, которые уже находятся «На сборке», дополнительный вопрос не требуется и их статус остаётся прежним.

Создание сборочного листа по-прежнему ничего не меняет в Wildberries: не создаёт поставку, не переносит заказы и не меняет статус WB.

## Установка

```bash
cd /opt/fulfillcore

mkdir -p backup_before_0.7.8.40
cp -a app backup_before_0.7.8.40/

unzip -o /root/FulfillCore_0.7.8.40_All_Status_Picking_Lists_Optional_Move_CUMULATIVE_FIX.zip -d /opt/fulfillcore

docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  restart api
```

Проверка:

```bash
sleep 10

docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  exec api python -c "from app.main import app; print(app.version)"
```

Ожидаемая версия: `0.7.8.40`.

После установки нажмите `Ctrl+F5` на каждом рабочем компьютере.

## Проверка

1. Откройте вкладку «Новые», ничего не отмечайте и нажмите «Создать сборочный лист».
2. На вопрос о переводе нажмите `Отмена`: Excel должен скачаться, а заказы должны остаться в «Новых».
3. Повторите создание и нажмите `ОК`: новые заказы должны перейти в «На сборке».
4. Откройте вкладку «На сборке» и сформируйте лист из всех заказов этой вкладки.

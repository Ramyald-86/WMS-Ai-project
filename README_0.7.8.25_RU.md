# FulfillCore 0.7.8.25 — WB CHZ Pending Status Freeze FIX

Точечный патч поверх 0.7.8.24. Печать, поставки, остатки и остальные рабочие модули не изменялись.

## Что исправлено

1. Если WB ещё проверяет ЧЗ (`pending`) или отклонил его, текущий статус заказа в FulfillCore не меняется.
2. Заказ больше не переходит автоматически из «Упаковано» в «На сборке» из-за неподтверждённого ЧЗ.
3. При ожидании или отказе сохраняются текущие `assembled_at` и `packed_at`.
4. Фоновая синхронизация также сохраняет текущий локальный статус, пока ЧЗ ожидает подтверждения WB.
5. Ручное изменение статуса продолжает работать отдельно.
6. После успешного подтверждения ЧЗ WB обычная упаковка по-прежнему переводит заказ в «Упаковано».

## Установка

Архив загружается на сервер в `/root` без распаковки, затем устанавливается поверх `/opt/fulfillcore`.

После перезапуска ожидаемая версия: `0.7.8.25`.

# FulfillCore 0.7.8.47

Накопительное обновление: содержит все изменения версий до `0.7.8.46` включительно. Отдельно устанавливать предыдущие архивы не требуется.

## Исправление печати ШК коробов

- Устранена ошибка `copies: Input should be less than or equal to 50`.
- Печать ШК коробов поставки теперь принимает от 1 до 1000 экземпляров за один запрос.
- Исправление действует и для автоматической печати через Print Agent, и для печати PDF через браузер.
- Количество `69`, показанное в ошибке, проходит проверку и печатается полностью.
- Формат этикетки, выбранный принтер и остальные операции с поставкой не изменялись.

## Установка

Распакуйте архив поверх `/opt/fulfillcore`, затем перезапустите контейнер API. Миграция базы данных не требуется. После перезапуска версия API должна быть `0.7.8.47`; на всех рабочих компьютерах нужно нажать `Ctrl+F5`.

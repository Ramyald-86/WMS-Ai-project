# FulfillCore 0.7.8.4 - точная печать 58x40

Обновление сохраняет изменения 0.7.8.3 (ЧЗ и диагностика складов WB) и исправляет геометрию печати.

## Что изменено

- Физическая страница товарной этикетки по умолчанию теперь **58x40 мм**.
- Вертикальный товарный макет 40x58 поворачивается **внутри PDF на 90°**, а не передаётся драйверу как страница 40x58. Это исключает обрезание и смещение на Xprinter с бумагой 58x40.
- Товарный макет: название/артикул/бренд/цвет/состав/страна/размер, крупный Code128 и цифры под ним. Пустые поля не печатаются.
- WB-стикер больше не растягивается. Он автоматически определяет ориентацию исходного изображения, поворачивается при необходимости, центрируется и вписывается в 58x40 с безопасным полем.
- В `Настройки печати` добавлены отдельные параметры для товарной и WB-этикетки:
  - ширина/высота бумаги;
  - поворот;
  - масштаб;
  - сдвиг X/Y в мм;
  - тестовая печать.
- При сканировании ЧЗ эти же настройки WB-этикетки используются для автоматической печати.

## Рекомендуемые значения для Xprinter

### Товарная
- Бумага: 58 x 40 мм
- Поворот: 90°
- Масштаб: 100%
- X: 0 мм
- Y: 0 мм

### WB
- Бумага: 58 x 40 мм
- Поворот: Автоматически
- Масштаб: 100%
- X: 0 мм
- Y: 0 мм

Если рамка/содержимое немного смещены конкретным драйвером, меняйте X/Y шагом 0.2-0.5 мм. Масштаб меняйте только если принтер физически подрезает край.

## Важно на Windows

В свойствах Xprinter размер бумаги также должен быть создан/выбран как **58 x 40 мм**. Print Agent 1.1.2 уже использует `noscale`, поэтому обновлять агент для этого патча не требуется.

## Установка

```powershell
scp "$env:USERPROFILE\Downloads\FulfillCore_0.7.8.4_Print_Calibration_FIX.zip" root@5.129.203.223:/root/
ssh root@5.129.203.223
```

На сервере:

```bash
cd /opt/fulfillcore
unzip -o /root/FulfillCore_0.7.8.4_Print_Calibration_FIX.zip -d /opt/fulfillcore

docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  restart api

sleep 10

docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  exec api python -c "from app.main import app; print(app.version)"
```

Ожидаемая версия: `0.7.8.4`.

После установки в Chrome нажать `Ctrl+F5`.

# FulfillCore 0.7.7.3 — быстрый ЧЗ WB

Изменения поверх 0.7.7.2:

- Сканирование ШК товара остаётся полностью локальным и не ждёт WB.
- При сканировании DataMatrix FulfillCore больше не создаёт поставку WB, не пытается повторно добавить заказ в поставку и не делает предварительные запросы статуса/meta.
- ЧЗ отправляется сразу в WB через операцию SGTIN. Ответ именно этой операции считается источником истины.
- DataMatrix передаётся без пересборки: сохраняется ASCII GS (0x1D); удаляются только префикс сканера ]d2 и завершающие CR/LF.
- Защита от дублей сохранена: ЧЗ уже привязанный текущему или другому заказу блокируется до обращения к WB.
- Отменённые/физически уехавшие заказы по-прежнему блокируются до отправки ЧЗ.
- Если WB принимает ЧЗ, он сразу сохраняется локально; затем запрашивается этикетка WB. Если этикетка ещё не готова, ЧЗ не теряется и повторно сканировать его не нужно.
- Если WB отклоняет SGTIN, заказ остаётся «На сборке», ЧЗ локально не считается принятым и показывается реальный ответ WB.

Это изменение специально убирает ошибочный путь FailedToAddSupplyOrder из операции сканирования ЧЗ и сокращает число синхронных запросов WB перед SGTIN с нескольких до нуля.

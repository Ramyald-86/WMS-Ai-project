# FulfillCore 0.7.9.5

Структурная массовая Excel-приёмка по схеме **секция → палета → короб → товар**.

## Что добавлено

- Новый двухэтапный режим на странице «Новая приёмка · Excel».
- Excel можно сначала загрузить **в черновик**: остатки и складская структура на этом этапе не изменяются.
- До проведения показываются секции, палеты, лимиты, короба, количество, пустые короба, ошибки и предупреждения.
- Поддерживается формат выгрузки «Адресное хранение»: `Секция`, `Паллета`, `Лимит`, `Короб`, `Партия`, `Источник`, `Принят на хранение`, `Дней`, `Объём м3`, `Начислено руб`, `Артикул`, `Размер`, `ШК товара`, `Остаток`.
- Заголовки распознаются и по нескольким безопасным алиасам; обязательны секция, палета, короб, ШК товара и остаток.
- По кнопке «Добавить на остатки» FulfillCore автоматически создаёт недостающие палетные адреса и физические короба, затем проводит товар одной складской приёмкой.
- Палетный адрес создаётся с понятным именем `Секция N · Палета M` и типом `PALLET`.
- Пустые строки товара сохраняют сам короб в структуре.
- Строки с количеством `0` не добавляют товар, но сохраняют короб и помечаются предупреждением.
- Повторная загрузка короба, в котором уже есть товар на складе, блокируется до проведения, чтобы не задвоить остатки.
- Пустой существующий короб того же клиента/склада может быть повторно использован и перемещён в место из Excel.
- Проверяется лимит коробов на палете, в том числе с учётом уже существующих коробов.
- Черновик можно удалить. Проведённую приёмку удалить напрямую нельзя — движение остаётся в истории склада.
- Можно скачать проверочный Excel с колонками «Статус строки / Ошибка / Предупреждение».
- Внутри черновика можно найти короб или товар по артикулу/ШК, сразу увидеть секцию, палету и открыть полный состав короба.
- В адресном хранении палеты из такого импорта группируются по секциям.
- Глобальный поиск адресного хранения теперь ищет также по номеру/ШК короба, поэтому после приёмки короб можно найти и открыть его палету.
- WB/Ozon при проведении структурной приёмки автоматически не изменяются. Как и раньше, публикация FBS-остатков остаётся отдельным контролируемым действием.

## Безопасность

- Существующие режимы ручной приёмки, обычной массовой приёмки, палетной приёмки, WB/Ozon, упаковки, ЧЗ, резервов и печати не заменялись.
- Проведение защищено межпроцессной блокировкой и повторной живой проверкой непосредственно перед изменением склада.
- Для каждой приёмки используется стабильный idempotency key, поэтому повторный запрос проведения не должен повторно прибавить товар.
- При ошибках проверки склад не меняется.

## Рекомендуемый порядок работы

1. Выбрать клиента и физический склад.
2. Открыть «Новая приёмка · Excel» → блок «Структурная приёмка».
3. Выбрать Excel и нажать «1. Загрузить и проверить».
4. Проверить секции, палеты, короба, количество и сообщения.
5. При необходимости скачать проверочный Excel и исправить исходный файл.
6. Когда ошибок нет — нажать «2. Добавить на остатки».
7. После проведения найти структуру в «Адресное хранение» → «Палеты», либо найти конкретный короб через строку поиска.

# FulfillCore 0.7.9.45

Точечный фикс массовой структурной Excel-приёмки.

- Формат названия короба больше не используется как системный barcode контейнера.
- Любая непустая строка в колонке «Короб» допустима: только цифры, BOX_..., буквы, пробелы и смешанные значения.
- Исходное значение из Excel остаётся видимым названием короба.
- Внутренний barcode нового короба FulfillCore формирует сам как FCBOX-...
- Одинаковые названия коробов у разных клиентов/складов больше не конфликтуют.
- Внутри одного клиента/склада прежняя защита от повторной загрузки непустого короба сохраняется.
- WB-карточка не блокирует физическую приёмку: корректный товар сначала попадает на локальный склад.
- WB FBS остаётся отдельным шагом синхронизации.

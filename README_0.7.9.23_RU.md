# FulfillCore 0.7.9.23

Точечное изменение ручной приёмки для товара, карточка которого ещё не найдена в локальном каталоге WB.

Что изменено:
- Позиции без карточки WB больше не блокируют приёмку остальных товаров.
- Кнопка «Принять найденные позиции» проводит только строки с найденной карточкой; строки без карточки остаются в черновике.
- Для оставшихся строк доступна Excel-выгрузка «Не найдено в WB» с ШК, артикулом, размером, названием, количеством, исходной ячейкой/коробом и причиной.
- Кнопка «Принять не найденные во внутренний учёт» принимает только проблемные строки локально и помещает их в виртуальную ячейку ПРИЕМКА.
- Внутренние проблемные позиции не создают очередь публикации в WB и не меняют остатки WB FBS.
- После появления карточки товар можно открыть в ПРИЕМКА и вручную разместить в реальную ячейку стандартным механизмом частичного размещения.
- Добавлен отдельный признак `wb_found`, чтобы локальный временный SKU не считался найденной карточкой WB до реального появления карточки.

Рабочие модули ЧЗ, упаковки, печати, сборочных листов 0.7.9.22 и остальная складская логика не переписывались.

Проверка:

```bash
python3 tools/smoke_check_0_7_9_23.py
```

Ожидаемый результат:

`OK: FulfillCore 0.7.9.23 unmatched-WB internal-receiving smoke-check passed`

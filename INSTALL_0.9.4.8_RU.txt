FULFILLCORE 0.9.4.8 REV2 — УСТАНОВКА
======================================

Цель версии: вернуть строгий рабочий цикл упаковки:
ШК товара -> ЧЗ -> подтверждение Wildberries -> этикетка WB -> фактическая печать Print Agent -> списание резерва -> Упаковано -> следующий товар.

ВАЖНО
- Print Agent на рабочих компьютерах НЕ переустанавливается этой серверной версией.
- Основа печати остаётся Print Agent 1.1.7 SAFE SIMPLE.
- Stock Core v2, FIFO, формирование сборочных листов и правила отменённых заказов не переписываются.
- Установщик сначала делает резервные копии и диагностику. При ошибке применения файлов автоматически возвращает старые файлы API.

1. НА WINDOWS-КОМПЬЮТЕРЕ ОТКРОЙТЕ POWERSHELL

PS C:\Users\...

cd $HOME\Downloads
scp .\FulfillCore_0.9.4.8_REV2_SEQUENTIAL_CONFIRMED_PRINT.zip root@201.24.52.218:/root/
ssh root@201.24.52.218

3. УСПЕШНЫЙ ФИНАЛ
В самом конце должно быть:

OK: FulfillCore 0.9.4.8 REV2 SEQUENTIAL_CONFIRMED_PRINT is running
FLOW: product -> CHZ -> WB confirmation -> WB label -> Print Agent ACK -> stock write-off -> PACKED -> next scan

Установщик также покажет:
- путь к диагностике до обновления;
- путь к реальным diff-файлам;
- путь к резервной копии;
- число idle in transaction старше 20 секунд;
- число старых 401 от неверно настроенных Print Agent.

4. ПОСЛЕ УСТАНОВКИ
- В браузере FulfillCore нажмите Ctrl+F5.
- Для первого теста используйте рабочее место с корректным токеном, например PACK-01.
- Проверьте ровно ОДИН заказ.

Ожидаемое поведение:
1) скан ШК товара;
2) скан ЧЗ;
3) поле следующего ШК заблокировано;
4) FulfillCore показывает ожидание WB;
5) после подтверждения ЧЗ получает этикетку WB;
6) этикетка физически выходит из принтера;
7) только после ACK принтера заказ становится «Упаковано», резерв списывается и поле следующего ШК разблокируется.

Если WB/принтер временно не ответил, заказ не должен молча становиться PACKED и ЧЗ не должен исчезать. Повторяется тот же ЧЗ, а не берётся следующий товар.

5. PRINT AGENT 1.1.7
Серверная установка обновляет только скачиваемую с сайта копию 1.1.7 SAFE SIMPLE. Уже установленный рабочий агент на ПК не трогается.

Сайт:
Настройки печати -> Скачать Print Agent

На новом ПК: распаковать ZIP, запустить INSTALL.bat, указать уникальный PACK-XX и токен именно этого рабочего места.

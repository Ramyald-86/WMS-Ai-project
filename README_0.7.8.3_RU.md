# FulfillCore 0.7.8.3

Изменения:
- товарная этикетка по умолчанию 40×58 мм, крупный макет на всю этикетку, штрихкод внизу;
- отдельная страница «Настройки печати»: размеры товарной и WB-этикетки, ориентация/поворот;
- WB-этикетка формируется в точном физическом размере (по умолчанию 58×40), без внутренних полей/уменьшения при конвертации;
- ЧЗ: сначала прямой запрос SGTIN в текущем состоянии заказа. Существующая/закрытая поставка больше не вызывает автоматический перенос заказа в другую поставку;
- техническая поставка создаётся только для реально NEW-заказа без supply_id, если WB вернул 409 и нужен confirm;
- диагностика складов WB и более устойчивое сопоставление по warehouseId + однозначному officeID;
- подготовка к проблеме Реутова: кнопка «Диагностика склада» показывает IDs, которые реально возвращают new/history endpoints WB.

Важно: WB официально принимает SGTIN только когда заказ допускает поле sgtin и находится в confirm. FulfillCore не обходит ограничения WB, а перестаёт ошибочно переносить заказы из уже существующих поставок.

# FulfillCore 0.7.8.35 — разделение физических складов

## Что изменено

- Верхний выбор «Склад» теперь является полноценным физическим контекстом работы.
- Для каждого физического склада отдельно сохраняются режимы складов WB: «Работа», «Наблюдение» и «Не показывать».
- Реутов и Мытищи могут одновременно работать в одном кабинете Wildberries под одним логином, не перезаписывая настройки друг друга.
- Заказы, синхронизация, поставки, сборка, сканирование товара и ЧЗ проверяются с учётом выбранного физического склада.
- Остатки, ячейки, палеты, короба, операции, резервы и очередь приёмки продолжают загружаться только для выбранного физического склада.
- При временной ошибке загрузки интерфейс больше не откатывается молча на предыдущий склад. Выбранный сверху склад сохраняется, чтобы оператор случайно не продолжил работу с чужими остатками.
- При первом открытии после обновления настройки WB нужно один раз сохранить отдельно для каждого физического склада. Старый общий выбор не применяется автоматически — это защищает от смешивания заказов.
- Второй логин для разделения складов не требуется. Один логин можно использовать одновременно на разных компьютерах.

## Первичная настройка после обновления

1. В верхнем поле «Склад» выберите `Реутов`.
2. Откройте раздел `Wildberries FBS`.
3. Нажмите `Обновить склады WB`.
4. Для склада WB, с которым работает Реутов, выберите `Работа`.
5. Ненужные для Реутова склады установите в `Не показывать` или при необходимости в `Наблюдение`.
6. Нажмите `Сохранить выбор`.
7. В верхнем поле «Склад» выберите `Мытищи`.
8. Повторите настройку и назначьте склад WB для Мытищ.
9. Переключитесь обратно на Реутов и убедитесь, что его выбор сохранился независимо.

После этого сотрудник в Реутове оставляет сверху `Реутов`, а сотрудник в Мытищах — `Мытищи`. Выбор сохраняется в браузере каждого рабочего компьютера.

## Установка

### 1. Скачайте архив

`FulfillCore_0.7.8.35_Physical_Warehouse_Isolation_FIX.zip`

### 2. Передайте архив на сервер из PowerShell и подключитесь

```powershell
scp "$env:USERPROFILE\Downloads\FulfillCore_0.7.8.35_Physical_Warehouse_Isolation_FIX.zip" root@5.129.203.223:/root/
ssh root@5.129.203.223
```

### 3. Сделайте резервную копию и установите обновление

```bash
cd /opt/fulfillcore
mkdir -p backup_before_0.7.8.35
cp -a app backup_before_0.7.8.35/
unzip -o /root/FulfillCore_0.7.8.35_Physical_Warehouse_Isolation_FIX.zip -d /opt/fulfillcore
```

### 4. Перезапустите API

```bash
docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  restart api
```

### 5. Проверьте версию

```bash
sleep 10
docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  exec api python -c "from app.main import app; print(app.version)"
```

Ожидаемый результат: `0.7.8.35`.

### 6. Обновите страницу

На каждом рабочем компьютере нажмите `Ctrl+F5`, затем один раз выполните настройку Реутова и Мытищ по инструкции выше.

## Быстрая проверка разделения

1. Выберите сверху `Реутов` и убедитесь, что отображается только назначенный ему склад WB.
2. Выберите сверху `Мытищи` и убедитесь, что его склад WB и заказы отличаются.
3. Измените режим одного склада WB в Мытищах, сохраните и вернитесь в Реутов — настройки Реутова не должны измениться.
4. На двух компьютерах одновременно оставьте разные физические склады и выполните синхронизацию WB.

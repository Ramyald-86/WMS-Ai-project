FulfillCore Print Agent 1.2.5 - ONE CLICK RELIABLE

Что исправлено относительно 1.2.3/1.2.4:
1. config.json всегда хранится в одном понятном месте: C:\printagent\config.json.
2. Агент после установки сразу запускается в фоне. START_AGENT вручную запускать не нужно.
3. Автозапуск создаётся двумя пользовательскими способами: Startup shortcut + HKCU Run.
4. Watchdog раз в минуту поднимает агент, если он завершился (если Task Scheduler разрешает создание задачи).
5. Защита от двух одновременно работающих Print Agent сохранена в самом агенте.
6. Используется логика печати 1.2.4: station-bound token, durable job journal, TSPL/ZPL, 203/300 DPI.
7. Установщик больше не может завершить сам себя из-за совпадения имени install_print_agent.ps1 / print_agent.ps1.

УСТАНОВКА НА НОВЫЙ ПК
1. Установите драйвер принтера и убедитесь, что Windows печатает тестовую страницу.
2. Распакуйте ZIP полностью в обычную папку. Не запускайте из архива.
3. Запустите START_INSTALL.cmd.
4. URL: обычно просто Enter, используется https://201-24-52-218.nip.io
5. Введите уникальный код рабочего места, например PACK-02.
6. Выберите номер Xprinter из списка.
7. Для Xprinter: язык 1 (TSPL), DPI 203, если принтер 203 dpi.
8. В FulfillCore откройте Настройки печати, создайте/выберите это рабочее место и скопируйте токен станции.
9. Вставьте токен в установщик.
10. Дождитесь INSTALL OK. После этого окно можно закрыть: агент уже работает в фоне.

ПРОВЕРКА
Запустите CHECK_AGENT.cmd. Должно быть:
- CONFIG: C:\printagent\config.json
- SERVER: OK
- TOKEN/STATION: OK
- PRINTER: FOUND
- BACKGROUND AGENT: RUNNING
- STARTUP SHORTCUT: OK
- HKCU RUN AUTOSTART: OK

Проверка после перезагрузки Windows:
- ничего вручную не запускайте;
- войдите в Windows;
- через 15-30 секунд запустите CHECK_AGENT.cmd;
- BACKGROUND AGENT должен быть RUNNING;
- отправьте одну тестовую этикетку из FulfillCore.

Если нужно поменять станцию, принтер или токен: RESET_AND_INSTALL.cmd.
Если нужно только посмотреть состояние: CHECK_AGENT.cmd.
Если нужно временно остановить агент: STOP_AGENT.cmd (watchdog может поднять его снова; для полного отключения сначала REMOVE_AUTOSTART.cmd).

ВАЖНО
Токен берётся из FulfillCore > Настройки печати для конкретной станции. Не используйте один токен/код станции на двух компьютерах одновременно.

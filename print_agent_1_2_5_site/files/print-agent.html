FulfillCore Print Agent 1.2.5

Актуальный установщик для Windows. После установки Print Agent сразу работает в фоне и автоматически запускается после входа в Windows. Ручной запуск START_AGENT не нужен.

Перед установкой

  1. Подключите принтер и установите драйвер.
  2. Распечатайте тестовую страницу средствами Windows.
  3. В FulfillCore откройте Настройки печати, выберите код рабочего места (например PACK-02) и нажмите кнопку показа токена.

Установка

  1. Скачайте ZIP и полностью распакуйте его в обычную папку. Не запускайте файлы прямо из ZIP.
  2. Запустите START_INSTALL.cmd.
  3. В поле FulfillCore URL обычно просто нажмите Enter. По умолчанию используется https://201-24-52-218.nip.io.
  4. Введите уникальный код рабочего места, например PACK-02.
  5. Выберите номер физического принтера из списка Windows.
  6. Для Xprinter обычно: 1 = TSPL, DPI — 203.
  7. Скопируйте токен именно этого рабочего места из FulfillCore и вставьте в установщик.
  8. Дождитесь зелёного сообщения INSTALL OK.

После INSTALL OK окно можно закрыть. Агент уже запущен скрыто в фоне.

Что исправлено в 1.2.5

  • Единый config: C:\printagent\config.json.
  • Фоновый запуск сразу после установки.
  • Автозапуск после входа в Windows через Startup + HKCU Run.
  • Watchdog восстанавливает агент после неожиданного завершения, если Windows разрешает создание задачи.
  • Нет ошибки, при которой установщик мог завершать сам себя.
  • Сохранена надёжная очередь/журнал печати 1.2.4 и защита от повторной физической печати одного job_id.

Проверка

Запустите CHECK_AGENT.cmd. Нормально, если отображается:

  • SERVER: OK
  • TOKEN/STATION: OK
  • PRINTER: FOUND
  • BACKGROUND AGENT: RUNNING
  • STARTUP SHORTCUT: OK
  • HKCU RUN AUTOSTART: OK

После перезагрузки компьютера ничего вручную не запускайте. Войдите в Windows, подождите 15–30 секунд и отправьте одну тестовую этикетку.

Важно: один код станции (например PACK-02) не должен одновременно использоваться на двух компьютерах. Для каждого рабочего места используйте свой код и его токен.

# FulfillCore 0.7.9.34

Точечный hotfix поверх 0.7.9.32.

- Печать A4 поставки больше не использует всплывающее окно.
- A4 открывается в текущей вкладке, поэтому блокировщик pop-up не мешает печати.
- На экранной версии A4 добавлена кнопка «Вернуться в FulfillCore».
- Автоматический вызов стандартного диалога печати браузера сохранён.
- WB, ЧЗ, остатки, упаковка, 58x40 и Print Agent не изменялись.

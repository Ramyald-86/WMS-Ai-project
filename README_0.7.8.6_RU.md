# FulfillCore 0.7.8.6 — DIRECT TSPL PRINT FIX

## Почему предыдущая схема печатала криво
PDF проходил сразу через несколько геометрий: размер страницы ReportLab -> SumatraPDF -> Windows driver -> профиль бумаги Xprinter. Даже `noscale` не гарантирует, что драйвер не применит свои поля/поворот/размер страницы.

## Новый подход
XP-420B печатает 203 DPI = 8 точек/мм и поддерживает TSPL. Поэтому рабочая печать этикеток теперь идёт не через PDF:

1. FulfillCore строит готовую этикетку сразу в физических точках принтера.
2. 58×40 мм = ровно 464×320 точек.
3. В очередь Print Agent отправляется PNG 464×320.
4. Print Agent 1.1.3 переводит PNG в 1-bit bitmap.
5. Bitmap отправляется в Xprinter как RAW TSPL `BITMAP`.
6. Windows, браузер, PDF и авто-поворот драйвера в геометрии этикетки не участвуют.

## Товарная этикетка
- физический формат 58×40;
- название и реквизиты строго в пределах этикетки;
- размер в отдельном блоке;
- нижняя зона зарезервирована под крупный сканируемый штрихкод;
- для валидного 13-значного кода используется EAN-13, иначе Code128;
- пустые поля не выводятся.

## Этикетка WB
- WB по-прежнему запрашивается как PNG 58×40;
- сервер нормализует изображение в 464×320;
- QR/DataMatrix/штрихкод переводятся в жёсткий ч/б растр без размытия;
- Print Agent печатает 1:1.

## После установки
1. Обязательно обновить Print Agent до 1.1.3 DIRECT TSPL.
2. В FulfillCore открыть `Настройки печати`.
3. Нажать `По умолчанию 58×40`.
4. Печать выбрать `Print Agent — точно 58×40`.
5. Масштаб 100%, X=0, Y=0.
6. Напечатать `Тест товарной 58×40`, затем тест WB.

Если после RAW TSPL весь макет целиком, но физически на 1–2 точки смещён относительно наклейки, это уже механическая калибровка принтера/датчика, а не масштаб документа.

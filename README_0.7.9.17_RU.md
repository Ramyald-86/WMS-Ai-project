# FulfillCore 0.7.9.17

База версии: 0.7.9.16. Логика экспериментальной 0.7.9.15 не переносилась.

## Изменения

1. Индикатор заполненности стандартного короба WB 60x40x40 см в зоне упаковки.
   - Использует габариты из уже синхронизированной карточки WB.
   - Показывает оценочный процент заполнения по объему, количество упакованных единиц и суммарный вес, если вес есть в карточках.
   - Текущий товар показывается до сканирования ЧЗ как прогноз.
   - В накопление товар попадает только после успешной упаковки (packed=true).
   - Состояние хранится отдельно для физического склада и упаковочного места.
   - Кнопка «Новый короб» обнуляет индикатор.
   - Если у карточки нет полных габаритов, упаковка не блокируется: индикатор сообщает об отсутствии данных.

2. Выделение заказов WB больше не пропадает от фонового обновления таблицы.
   - Отмеченные заказы сохраняются при обычном refresh/sync той же страницы.
   - При явном переходе на другую вкладку статуса или другую страницу выбор очищается, чтобы невидимые заказы случайно не попали в массовую операцию.

3. Отмена после сборочного листа.
   - Источником истины теперь является наличие настоящего picking list, а не промежуточный local_status в момент прихода отмены.
   - Если товар уже вошел в сборочный лист и еще не был упакован, отмена направляет единицу только в виртуальную зону «ПРИЕМКА / требует размещения».
   - В исходную ячейку автоматически товар не возвращается.
   - Если заказ уже был упакован, товар остается списанным как уехавший на WB.
   - Экран ПРИЕМКА автоматически и идемпотентно чинит старые отмены, которые предыдущая версия могла пропустить из-за сменившегося статуса.

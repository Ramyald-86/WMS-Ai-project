# FulfillCore 0.7.9.24

Точечное улучшение раздела «Склад → Остатки».

Что изменено:
- Добавлена кнопка «Выгрузить остатки в Excel».
- Выгрузка учитывает текущий поиск и фильтр наличия.
- В Excel отдельно показаны: остаток на физическом складе FulfillCore, опубликованный остаток WB FBS, разница, статус FBS и ячейки/короба.
- В таблице остатков визуально разделены «На складе» и «WB FBS».
- В сводке над таблицей одновременно показывается сумма единиц на складе и сумма опубликованных единиц FBS.
- Локальные позиции без карточки WB отображаются как внутренний учёт и в FBS считаются 0 до ручной публикации.

Формат выгрузки — Excel-совместимый `.xls`, открывается обычным Microsoft Excel без дополнительных библиотек на сервере.

Рабочие модули приёмки, ЧЗ, упаковки, печати и сборочных листов не переписывались.

Проверка:

```bash
python3 tools/smoke_check_0_7_9_24.py
```

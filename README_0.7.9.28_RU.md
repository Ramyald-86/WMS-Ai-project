# FulfillCore 0.7.9.28 — структурная Excel-приёмка: удаление, массовый WB FBS и состав короба

Версия продолжает 0.7.9.27 и исправляет функции именно для нового экрана «Новая приёмка · Excel» (структурная приёмка секция → палета → короб → товар).

Что исправлено:
- у принятой структурной приёмки появилась видимая кнопка «Удалить приёмку» / «Удалить / отменить приёмку»;
- удаление принятой приёмки безопасно делает обратную складскую операцию и снимает принятый товар с локальных остатков; история сохраняется со статусом «Приёмка отменена»;
- если часть товара уже физически ушла и количества для полного отката не хватает, отмена блокируется без частичного изменения;
- после принятия структурной приёмки появляется блок «Массово разместить товары этой приёмки на FBS»;
- в блоке есть чекбоксы, «Выбрать все доступные» и «Отправить выбранные на WB FBS»;
- по каждой позиции видно количество в этой приёмке, текущий общий остаток FulfillCore и последний опубликованный остаток WB FBS;
- на WB отправляется точный текущий складской остаток по отмеченному ШК (SET), поэтому повторная отправка не прибавляет количество второй раз;
- товары без найденной карточки WB видны, но недоступны для отправки;
- «Состав» короба теперь открывается в отдельном модальном окне поверх страницы, поэтому состав виден сразу даже в длинной приёмке;
- черновики по-прежнему можно удалить без изменения склада;
- упаковка, ЧЗ, печать, сборочные листы и остальные рабочие модули не переписывались.

После установки выполните:

`python3 tools/smoke_check_0_7_9_28.py`

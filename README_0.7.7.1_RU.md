# FulfillCore 0.7.7.1

Исправление сканирования ЧЗ при ошибке WB `FailedToAddSupplyOrder` (409).

- Если заказ уже связан с поставкой WB, FulfillCore больше не создаёт лишнюю новую поставку.
- При 409 после добавления заказа в поставку FulfillCore повторно читает точный статус заказа и не блокирует упаковку на промежуточной ошибке.
- Финальным подтверждением становится сам запрос записи SGTIN: если WB принимает ЧЗ, работа продолжается; если нет — показывается прямой ответ WB.
- Все функции 0.7.7.0 сохранены.

# FulfillCore 0.7.9.35 — надёжная приёмка + WB FBS

- Массовая Excel-приёмка по умолчанию сразу обновляет WB FBS после локального проведения.
- Если WB отклонил часть строк, локальный склад сохраняется, а только ошибочные ШК остаются в очереди повторной отправки.
- При подключённом WB весь Excel сначала проверяется по точному ШК карточки выбранного клиента. При ошибках остатки вообще не меняются.
- Артикул, размер и название короба — информационные поля; сопоставление WB выполняется по точному ШК.
- Проверка добавлена массовой, палетной и структурной Excel-приёмке.
- Добавлены скачиваемые шаблоны для 5 колонок, 2 колонок, палетной раскладки и структурной приёмки.
- ШК в шаблонах имеет текстовый формат.
- Палетная и структурная приёмка по умолчанию также сразу обновляют WB FBS; при необходимости можно выбрать «Только FulfillCore».
- Ручная приёмка и остальные рабочие модули не переписывались.

# FulfillCore 0.7.8.26 — WB CHZ Closed Supply Safe Retry FIX

Точечный патч поверх 0.7.8.25. Печать, остатки, обычная сборка и остальные рабочие модули не изменялись.

## Что исправлено

1. FulfillCore пытается передать ЧЗ напрямую в WB и обязательно проверяет фактическое принятие кода.
2. Для заказа в закрытой поставке программа сначала проверяет, не закреплён ли ЧЗ уже, затем безопасно пробует передачу без изменения поставки.
3. Если WB не принял ЧЗ напрямую, перенос в активную поставку выполняется только для заказа, который WB включил в «Повторную отгрузку».
4. Обычный заказ из закрытой поставки больше не отвязывается от своей поставки и не переносится в служебную поставку.
5. Если WB не разрешает присвоение, ЧЗ остаётся сохранённым в FulfillCore, а локальный статус, поставка и временные отметки заказа не меняются.
6. После успешной проверки ЧЗ в WB заказ переводится в «Упаковано» по прежней рабочей схеме.

## Установка

Архив загружается на сервер в `/root` без распаковки, затем устанавливается поверх `/opt/fulfillcore`.

После перезапуска ожидаемая версия: `0.7.8.26`.

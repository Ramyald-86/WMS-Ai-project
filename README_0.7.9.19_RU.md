# FulfillCore 0.7.9.19

Точечное продолжение 0.7.9.18. Логика экспериментальной 0.7.9.15 не используется.

Что изменено:

- Упаковка теперь отдельно распознаёт товар, который находится в виртуальной ячейке `ПРИЕМКА`. Если для отсканированного ШК нет подходящего заказа `На сборке`, но физический остаток есть в `ПРИЕМКА`, FulfillCore показывает понятное предупреждение: сначала разместить товар в реальную ячейку/палету, затем продолжать упаковку.
- В предупреждении на упаковке есть кнопка `Открыть ПРИЕМКА`.
- В виртуальной `ПРИЕМКА` у каждой позиции появилась кнопка `Разместить`: можно отсканировать QR/ввести код реального адреса, выбрать количество и сразу выполнить перемещение из виртуальной зоны.
- Из содержимого обычной ячейки можно открыть складскую карточку товара (`Карточка товара`), если товар сопоставлен с карточкой WB.
- Для позиций в `ПРИЕМКА` также доступна карточка товара при наличии сопоставления с WB.
- Индикатор заполненности больше не показывает 101%, 163% и подобные значения. WB хранит габариты упаковки/товара, и простая сумма объёмов может быть больше реального объёма уложенного мягкого товара. В интерфейсе процент теперь ограничен 100%; если расчётный объём WB выше 96 л, это явно подписывается как оценка по габаритам WB.

Правило остатков не изменено: товар, попавший в настоящий сборочный лист, не возвращается автоматически в старую ячейку. До упаковки отменённая физическая единица ждёт повторного размещения в виртуальной `ПРИЕМКА`.

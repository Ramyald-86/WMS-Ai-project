# FulfillCore 0.7.8.32 — ячейки, остатки и история склада

## Что изменено

- Проход при создании адресов теперь необязателен.
- Добавлен мастер: проход → стеллаж/палеты → этажи → диапазон ячеек.
- Стеллажные ячейки создаются массово по диапазонам этажей и номеров.
- Палеты создаются по одной или диапазоном; номер можно пропустить.
- Каждому новому адресу назначается уникальный штрихкод.
- Этикетки можно открыть для печати по одной, для выбранных ячеек, диапазона или всех адресов склада.
- Карточка ячейки показывает весь её состав: товар, размер, ШК, короб и количество.
- В остатках по умолчанию показываются только позиции в наличии; доступны режимы «Все» и «Нет в наличии».
- Из карточки товара можно добавить остаток или списать товар с выбранной ячейки/короба. Списание подтверждается и сохраняется в истории.
- Удаление приёмки доступно как из списка, так и из открытой приёмки. Для заполненной приёмки предусмотрено отдельное подтверждение принудительного удаления структуры; остатки товара случайно не удаляются.
- История приёмки и перемещений получила поиск, понятные типы операций и отдельное отображение даты и времени.

## Установка

### 1. Скачайте архив

`FulfillCore_0.7.8.32_Locations_Inventory_History_FIX.zip`

### 2. Передайте архив на сервер из PowerShell и подключитесь

```powershell
scp "$env:USERPROFILE\Downloads\FulfillCore_0.7.8.32_Locations_Inventory_History_FIX.zip" root@5.129.203.223:/root/
ssh root@5.129.203.223
```

### 3. Создайте резервную копию и распакуйте обновление

```bash
cd /opt/fulfillcore
mkdir -p backup_0.7.8.31_before_0.7.8.32
cp -a app backup_0.7.8.31_before_0.7.8.32/
unzip -o /root/FulfillCore_0.7.8.32_Locations_Inventory_History_FIX.zip -d /opt/fulfillcore
```

### 4. Перезапустите API

```bash
docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  restart api
```

### 5. Проверьте версию

```bash
sleep 10
docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  exec api python -c "from app.main import app; print(app.version)"
```

Ожидаемый результат: `0.7.8.32`.

После установки обновите страницу сочетанием `Ctrl+F5`.

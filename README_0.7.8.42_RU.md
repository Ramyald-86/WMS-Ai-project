# FulfillCore 0.7.8.42

Накопительное обновление: содержит все исправления до версии 0.7.8.41 включительно. Пропущенные обновления отдельно устанавливать не нужно.

## QR-этикетка ячейки

- Линейный штрихкод на этикетке адреса заменён на крупный QR.
- Номер ячейки напечатан сверху по центру, например `1-3-16`.
- В QR записывается прежний внутренний код адреса `FCLOC-...`, поэтому приёмка, перемещение, поиск и сканирование продолжают работать без изменения данных.
- Пересоздавать существующие ячейки не нужно.
- Новый формат применяется при печати одной ячейки, выбранных адресов, диапазона или всех адресов.
- Размер этикетки по умолчанию остаётся `58×40 мм`.

## Предыдущие исправления сохранены

- Безопасное одиночное и массовое удаление пустых ячеек, палет и коробов с сохранением истории.
- Приёмка прямо в ячейку без обязательного короба.
- Выбор назначения при приёмке: только FulfillCore или FulfillCore + WB FBS.
- Отмена ошибочной приёмки обратной операцией.
- Контроль размещения остатков FBS и установка на WB точного текущего остатка FulfillCore без сложения.
- Восстановление печати этикетки WB для упакованного активного заказа.
- Защита упакованного заказа от ошибочного возврата в «На сборке».
- Быстрая обработка ЧЗ и защита от повторной автопечати.
- Раздельные настройки складов WB для физических складов.
- Фильтр по брендам с выбором одного или нескольких значений.
- Сборочные листы по всем заказам статуса без ограничения строк текущей страницы и без обязательного перевода новых заказов в «На сборке».

## Установка

```bash
cd /opt/fulfillcore

mkdir -p backup_before_0.7.8.42
cp -a app backup_before_0.7.8.42/

unzip -o /root/FulfillCore_0.7.8.42_Location_QR_Label_CUMULATIVE_FIX.zip -d /opt/fulfillcore

docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  restart api
```

Проверка версии:

```bash
sleep 10

docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  exec api python -c "from app.main import app; print(app.version)"
```

Ожидаемая версия: `0.7.8.42`.

После установки нажмите `Ctrl+F5` на каждом рабочем компьютере.

## Короткая проверка

1. Откройте `Склад → Ячейки / палеты`.
2. Выберите тестовую ячейку, например `1-3-16`, и нажмите `Этикетка`.
3. На этикетке сверху должен быть номер `1-3-16`, ниже — крупный QR.
4. Отсканируйте QR в поле ячейки приёмки или перемещения: должна найтись та же ячейка.

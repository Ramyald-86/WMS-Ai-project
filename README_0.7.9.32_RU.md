# FulfillCore 0.7.9.34

Точечное изменение относительно 0.7.9.31.

- Кнопка «Печать A4» показывается у открытых и закрытых поставок WB.
- Перед печатью оператор вручную вводит количество единиц товара.
- A4 открывается в браузере и печатается стандартным диалогом браузера/Windows.
- Print Agent для A4 не используется.
- Печать A4 не закрывает поставку и не меняет ее состав/статус.
- Для открытой поставки используется безопасное локальное представление кода поставки, поскольку WB может не отдавать официальное изображение до закрытия.
- Существующие пути 58x40, Print Agent, заказы, ЧЗ, остатки и упаковка не изменялись.

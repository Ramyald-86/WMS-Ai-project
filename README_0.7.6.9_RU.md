# FulfillCore 0.7.6.9 — ручной импорт данных WB

Добавлена отдельная кнопка «Импортировать данные WB» на рабочем месте Wildberries FBS.

Обычная синхронизация и фоновое обновление остаются лёгкими. Ручной импорт проходит всю рабочую очередь выбранного склада WB и подтягивает внешние коды маркировки, этикетки и актуальные статусы. В первую очередь проверяются «Новые» и «На сборке». Запросы идут ограниченными пачками; при лимите WB уже полученные изменения сохраняются, а импорт можно повторить позже.

Все функции 0.7.6.8 сохранены, включая палетную приёмку.

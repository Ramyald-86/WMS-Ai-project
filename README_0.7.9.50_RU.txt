FulfillCore 0.7.9.50

- У одной карточки/размера WB может быть несколько ШК.
- Любой ШК из карточки считается допустимым алиасом одной позиции.
- Массовая приёмка не должна блокироваться из-за того, что в WB основным отображается другой ШК.
- Локальный остаток считается только по фактическим InventoryBalance.
- Остатки всех ШК одной карточки суммируются в одну складскую позицию.
- Поиск работает по любому ШК карточки.
- Для действий выбирается ШК, на котором реально есть локальный остаток.

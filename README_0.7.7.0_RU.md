# FulfillCore 0.7.7.0

Изменения поверх 0.7.6.9:

- Палетная приёмка: удаление ошибочно отсканированного короба до загрузки товарной раскладки.
- Повторный скан короба больше не проходит молча: появляется подтверждение «Вы уверены, что хотите принять этот короб?». После подтверждения один физический короб не дублируется как новая сущность, а остаётся/переназначается на текущую палету.
- Лимит палеты — 16 коробов. После 16-го короба палета автоматически закрывается и создаётся/активируется следующая палета.
- Если палета неполная, кнопка «Закрыть палету → следующая» закрывает её вручную и переводит сканирование на следующую.
- ЧЗ: если у текущего товара/заказа уже есть ЧЗ, новый код не отправляется в WB; интерфейс получает предупреждение с номером заказа и текущим ЧЗ.
- ЧЗ: один и тот же код нельзя использовать для разных заказов. При повторном скане показывается номер заказа, к которому он уже привязан.
- Остальная логика 0.7.6.9 (ручной импорт WB, приёмка, палеты/короба, FBS, статусы, интерфейс) сохранена.

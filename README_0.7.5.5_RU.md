# FulfillCore 0.7.5.5 — scan + speed + targeted WB meta

Что исправлено:
- Сканирование товара ищет заказ по внутреннему статусу FulfillCore «На сборке» и больше не требует supplierStatus=confirm уже на первом шаге.
- При сканировании конкретного товара FulfillCore сразу обновляет CHZ/этикетку именно этого заказа из WB, поэтому внешний CHZ не ждёт фоновой очереди.
- Видимые на экране заказы получают фоновое обновление метаданных чаще.
- Таблица заказов сериализуется пакетно: SKU, остатки, карточки и сборочные листы загружаются группами вместо сотен отдельных SQL-запросов. Это ускоряет переключение статусов и страниц.
- Фоновые локальные опросы разрежены, чтобы не конкурировать с кликами пользователя.
- Debounce сканера уменьшен до 80 мс.

Важно:
- «На сборке» по-прежнему определяется только действиями FulfillCore.
- Фактические транспортные wbStatus по-прежнему имеют приоритет для «Доставляется/Получен/Отменён».

# FulfillCore 0.7.9.21

## Сборочный лист не блокируется нехваткой остатка

Точечное накопительное исправление поверх 0.7.9.20.

- Если для выбранного заказа не хватает свободного товара в физических ячейках, сборочный лист всё равно создаётся.
- Для недостающей позиции в листе ставится статус `НЕ ХВАТАЕТ`.
- Ячейка и короб для такой позиции не указываются.
- Если остаток был доступен при расчёте листа, но до фиксации его уже забрал другой сборочный лист, весь лист больше не падает с 409: только конкретная позиция переводится в `НЕ ХВАТАЕТ`.
- Списание выполняется только для реально распределённых строк со статусом `OK`.
- Упаковка/ЧЗ/печать и частичное размещение из виртуальной ПРИЕМКА из 0.7.9.20 не переписывались.
- Экспериментальная FAST_CHZ_NONBLOCKING-логика 0.7.9.15 не возвращалась.

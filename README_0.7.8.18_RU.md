# FulfillCore 0.7.8.18 — CHZ для заказа из закрытой поставки / повторная отгрузка

Точечный патч. Не меняет печать, интерфейс, статусы очередей, приёмку или Print Agent.

Исправление:
- если WB отвечает 409 при записи ЧЗ и заказ имеет supplierStatus=complete из закрытой поставки, FulfillCore проверяет официальный список повторной отгрузки GET /api/v3/supplies/orders/reshipment;
- если заказ есть в списке, FulfillCore переносит его в активную техническую поставку, проверяет фактический переход в confirm и повторяет запись ЧЗ один раз;
- если заказа нет в списке повторной отгрузки, состояние не изменяется и UI показывает понятную причину вместо бессмысленной попытки переноса.

Также сохранено исправление отображения версии из 0.7.8.17.

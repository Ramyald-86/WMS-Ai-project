# FulfillCore 0.7.7.8 — Receiving navigation / fixed sidebar / inventory modal

Изменения поверх 0.7.7.7:

- Исправлено открытие складской карточки из «Остатков»: возвращено отсутствовавшее модальное окно inventoryProductModal.
- Левое меню на desktop закреплено и больше не уезжает/остаётся наверху при прокрутке длинных страниц и карточек WB.
- «Палеты и короба» переименовано в «Приёмка» и стало главным разделом приёмок.
- Старая ручная «Приёмка» убрана как отдельный пункт меню и доступна из «Приёмка → Новая приёмка → Ручная приёмка».
- В ручной и Excel-приёмке добавлена кнопка «← Приёмка»; в палетной приёмке кнопка возврата также ведёт в главный раздел.
- Исправлена прокрутка структуры палет: правая панель имеет собственную высоту и собственный vertical scroll, левая панель больше не перекрывает структуру.
- Структура и сканирование ограничены в отдельной рабочей области; Excel-блок расположен ниже и не залезает на список палет.
- Остальная логика 0.7.7.7 сохранена.

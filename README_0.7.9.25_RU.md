# FulfillCore 0.7.9.25

Точечное обновление сборочных листов WB.

Что изменено:
- можно формировать новый сборочный лист из заказов, которые уже находятся в статусе «На сборке»;
- если заказ уже был в реальном сборочном листе и остаток был списан, новый лист повторно остаток НЕ списывает;
- для такого заказа используется сохранённая ячейка/короб из предыдущего сборочного листа;
- можно сделать один новый консолидированный лист из заказов «На сборке», даже если раньше они находились в разных листах;
- если заказ был вручную переведён в «На сборке», но реального сборочного листа у него ещё не было, при первом реальном листе остаток списывается штатно;
- заказы без остатка по-прежнему не блокируют лист и выводятся как «НЕ ХВАТАЕТ» без ячейки;
- упаковка, ЧЗ, печать и WB API не переписывались.

Проверка:

```bash
python3 tools/smoke_check_0_7_9_25.py
```

Ожидается:
`OK: FulfillCore 0.7.9.25 PICKING rebuild/reprint smoke-check passed`

# FulfillCore 0.7.8.14 CUMULATIVE

Кумулятивный точечный патч для установки непосредственно поверх 0.7.8.12.
Отдельно устанавливать 0.7.8.13 и предыдущий 0.7.8.14 не требуется.

Включает два изменения:

1. Исправление классификации статусов WB из 0.7.8.13:
   - `supplierStatus=confirm` и `supplierStatus=complete` сами по себе не означают физическую отправку;
   - без факта движения WB такие заказы остаются рабочими и не попадают ошибочно в «Отправлены»;
   - реальные транспортные статусы WB, отмена, получение и ручной статус продолжают иметь приоритет.

2. UI и ручное изменение статуса из 0.7.8.14:
   - блоки WB адаптивно переносятся и не должны залезать друг на друга;
   - вместо отдельных массовых кнопок используется список «Изменить статус выбранных»;
   - доступны «Новые», «На сборке», «Отправлены»;
   - в «Отправлены» вручную можно переводить только упакованные заказы (или уже отправленные).

Не изменяются: ЧЗ, печать, Print Agent, поставки, приёмка и остальные рабочие модули.

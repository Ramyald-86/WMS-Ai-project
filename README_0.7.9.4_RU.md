# FulfillCore 0.7.9.4 — массовая QR-печать и освобождение ЧЗ отменённого заказа

Точечный релиз поверх 0.7.9.3. Складская логика резервов и правило 0.7.9.2 для отмены после PACKED не изменены.

Что исправлено:
- Массовая печать QR ячеек больше не собирает многостраничный PDF через `pypdf`/`PyPDF2`. Все страницы 58x40 мм рисуются сразу одним ReportLab-документом. Это убирает серверный `Internal Server Error` на установках, где PDF-merger не входил в образ, и уменьшает лишние операции памяти/CPU.
- Print Agent 1.1.7 не является причиной этого HTTP 500: ошибка возникала на сервере до постановки задания в очередь. Для многостраничного PDF 1.1.7 с настроенным SumatraPDF совместим; 1.2.0 всё равно рекомендуется из-за более надёжного журнала, профилей DPI и привязки к PACK-станции.
- Если после успешного сканирования товара и ЧЗ WB-этикетка не получается именно потому, что WB подтвердил отмену этого заказа, FulfillCore делает свежую точечную проверку статуса заказа и только после подтверждения отмены освобождает ЧЗ.
- Если ЧЗ виден в метаданных WB, FulfillCore удаляет `sgtin` через официальный `DELETE /api/v3/orders/{orderId}/meta?key=sgtin`; локальная привязка очищается только после успешного удаления либо когда точное чтение метаданных показывает, что кода там уже нет.
- Если WB не подтвердил удаление метаданных, ЧЗ не освобождается локально: это защищает от случайного повторного использования одного кода на двух заказах.
- При автоматическом освобождении отменяются только ещё не напечатанные WB-этикетки этого отменённого заказа. Сам отменённый заказ остаётся CANCELLED.
- Правило остатков не менялось: отмена после PACKED остаётся списанной и не возвращается автоматически в ПРИЕМКА. Освобождается только ЧЗ, как отдельная операция.
- Для ошибок API браузер теперь сохраняет код/данные ответа. Поэтому фоновая упаковка отличает «обычную ошибку печати» от специального случая `WB_ORDER_CANCELLED_CHZ_RELEASED` и показывает правильное сообщение упаковщику.

Не изменено:
- ускоренный pipeline ШК/ЧЗ 0.7.9.3;
- резервы сборочных листов 0.7.9.1;
- правило PACKED-cancel 0.7.9.2;
- логика обычной печати WB, если заказ активен;
- приёмка, остатки, размещение и Ozon.

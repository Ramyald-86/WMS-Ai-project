# FulfillCore 0.7.9.14 — DB Pool Reliability

Точечное исправление 30-секундных зависаний и `Internal Server Error`, вызванных исчерпанием SQLAlchemy QueuePool (`size 5 / overflow 10 / timeout 30s`).

Изменения:
- пул по умолчанию увеличен до 20 постоянных + 20 overflow соединений;
- ожидание свободного подключения сокращено до 5 секунд;
- включены `pool_pre_ping` и recycle 900 секунд;
- при старте idle-пул пересоздаётся с новыми параметрами;
- добавлена диагностика `/health/db-pool`;
- параметры можно менять переменными `FC_DB_POOL_SIZE`, `FC_DB_MAX_OVERFLOW`, `FC_DB_POOL_TIMEOUT`, `FC_DB_POOL_RECYCLE` без переписывания кода.

Это программная проблема, для текущей нагрузки покупать более мощный сервер из-за этой ошибки не требуется.

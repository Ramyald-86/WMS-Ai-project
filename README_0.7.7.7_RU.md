# FulfillCore 0.7.7.7

Изменения поверх 0.7.7.6:

- «Остатки»: исправлены названия и порядок колонок: Фото → Товар → Артикул → Размер → ШК → Короб / ячейка → Количество → действие.
- Строка остатка и кнопка «Открыть» открывают складскую карточку товара.
- «Палеты и короба» разделены на два экрана: создание/история приёмок и отдельная рабочая страница выбранной приёмки.
- На первом экране показаны предыдущие приёмки с датой/временем, количеством палет и коробов; открытие выполняется отдельной кнопкой.
- Добавлен выбор способа приёмки: палеты→короба, переход к массовой Excel-приёмке или ручной приёмке.
- Структура палет получила собственную вертикальную прокрутку; основная страница больше не должна уезжать при просмотре 16 коробов.
- Левая панель сканирования стала уже, правая структура получила больше места; устранено визуальное наложение соседних блоков.
- Добавлена выгрузка выбранной палетной приёмки в Excel: палета, короб, текущий товар в коробе, статус палеты и время сканирования.
- Сохранены удаление с подтверждением, автопереход после 16 коробов, ручное закрытие неполной палеты и загрузка товарной раскладки.

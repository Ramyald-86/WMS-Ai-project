# FulfillCore 0.7.8.50

Накопительное обновление поверх 0.7.8.49. Включает все предыдущие исправления.

## Печать QR-этикеток ячеек

- Автоматическая печать через Print Agent больше не использует PDF-драйвер, который разворачивал и обрезал этикетку.
- Каждая этикетка отправляется как отдельный PNG 464×320 точек для прямой печати 58×40 мм.
- Номер ячейки остаётся горизонтально сверху, QR `FCLOC-...` — по центру ниже.
- Внутри страницы выбранной полки добавлены списки `С ячейки` и `По ячейку`.
- Кнопка `Печать диапазона` отправляет все ячейки между выбранными границами, включая обе границы.
- Ручная печать нескольких отмеченных ячеек переведена на пакетный POST-запрос и больше не зависит от длины URL или блокировки нового окна.
- Ручной режим по-прежнему формирует единый многостраничный PDF.

## Ozon FBS

- Проверка подключения Ozon больше не зависит только от метода получения складов.
- Ошибка подключения показывает понятный ответ Ozon и сохраняется в карточке подключения.
- Добавлен выбор склада Ozon; выбор хранится отдельно для каждого физического склада FulfillCore.
- Если API-ключ не может получить справочник складов, список безопасно восстанавливается из метаданных FBS-отправлений.
- Статусы отправлений показаны по-русски; упакованные позиции выделены отдельно.
- Добавлена кнопка `Создать отгрузку из упакованных`.
- Перед созданием FulfillCore повторно проверяет актуальный статус каждого отправления в Ozon.
- Неупакованные отправления в отгрузку не принимаются.
- Отправления группируются по способу доставки, после создания задаётся точный выбранный состав.
- Создаётся только документ отгрузки. Подтверждение и фактическая передача перевозчику выполняются отдельно.
- При частичной ошибке FulfillCore показывает возможные ID созданных отгрузок и блокирует рекомендацию повторного нажатия до проверки кабинета Ozon.

## Массовая приёмка Excel

- В формате 5 колонок первый столбец теперь всегда означает физический короб.
- Значение больше не может случайно превратиться в ячейку из-за совпадения названия.
- Новый короб сразу создаётся в зоне `ПРИЕМКА`.
- Короб и его название видны в сборочном листе.
- После импорта короб доступен в разделе `Короба`: его можно открыть, переименовать и целиком переместить в ячейку или на палету.
- Ошибочная строка с пустым ШК или количеством больше не создаёт пустой короб.
- WB и Ozon при массовой приёмке автоматически не изменяются.

## Приёмка палет и коробов

- Сначала создаётся документ приёмки.
- При сканировании короба сразу создаётся настоящий пустой короб FulfillCore в зоне `ПРИЕМКА-ПАЛЕТЫ`.
- Короб виден в общем разделе коробов до загрузки товарной раскладки.
- После этого короб можно заполнить товаром через раскладку, переименовать или переместить в рабочую ячейку.
- Повторный короб не создаёт вторую физическую сущность.
- Короб с товаром нельзя повторно принять как пустой.
- Один короб нельзя одновременно держать в двух активных приёмках.
- Удаление ошибочной открытой приёмки архивирует только созданные ею пустые короба, оставшиеся в зоне приёмки.
- Короб, уже перемещённый оператором в рабочую ячейку, при удалении приёмки не исчезает.
- Связь приёмки с коробом хранится по внутреннему ID, поэтому переименование не ломает последующее заполнение.

## Wildberries

Логика WB не изменялась. Остатки и поставки WB по-прежнему не меняются без отдельного явного действия и подтверждения пользователя.

## Проверка после установки

1. В режиме `Print Agent` напечатайте одну ячейку: номер должен быть горизонтально сверху, QR — полностью внутри 58×40 мм.
2. Откройте стеллаж → этаж/полку, выберите диапазон, например с ячейки 10 по 23, и убедитесь, что поставлено в очередь 14 этикеток.
3. Переключите печать в ручной режим, отметьте несколько ячеек галочками и нажмите `Печать выбранных QR`: должен открыться единый PDF.
4. В `Личном кабинете` выберите подключение Ozon и нажмите `Проверить`.
5. Откройте `Ozon FBS`, выберите склад и обновите отправления.
6. Выберите одно или несколько отправлений со статусом `Упаковано · готово к отгрузке`.
7. Нажмите `Создать отгрузку из упакованных`, подтвердите действие и проверьте ID в кабинете Ozon.
8. Импортируйте тестовый Excel 5 колонок и убедитесь, что первый столбец появился как короб в сборочном листе и разделе `Короба`.
9. Создайте палетную приёмку, добавьте палету и один короб: короб должен сразу показываться как пустой и созданный в системе.

# FulfillCore 0.7.7.6 — удобная палетная приёмка

Изменения поверх 0.7.7.5:

- Переделан интерфейс «Палеты и короба»: слева компактная зона сканирования, справа широкая структура приёмки.
- Палеты отображаются отдельными вертикальными карточками, а короба — строго списком по одному на строку.
- У каждой палеты виден счётчик заполнения X/16, статус и количество товара.
- Старые палеты автоматически сворачиваются; текущая/последняя раскрыта. Палету можно раскрыть/свернуть кликом по заголовку.
- Добавлена сводка: количество палет, коробов и товаров.
- Список структуры имеет собственную прокрутку и больше не растягивает всю страницу.
- Удаление коробов/палет и подтверждения сохранены.
- Вся логика 0.7.7.5, включая исправления WB/ЧЗ и карточек товаров, сохранена.

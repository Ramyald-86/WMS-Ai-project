# FulfillCore 0.7.9.42

Исправление синхронизации остатков WB FBS.

- Перед отправкой проверяется, что warehouseId реально присутствует в GET /api/v3/warehouses выбранного кабинета WB.
- officeId и внутренний UUID склада FulfillCore не могут быть использованы как warehouseId.
- ШК из FulfillCore используется как точный идентификатор для поиска размера в карточке WB.
- По актуальной документации WB PUT /api/v3/stocks/{warehouseId} принимает stocks: [{chrtId, amount}], а не nmId/внутренний артикул.
- Если локальный chrtId устарел, FulfillCore перечитывает живой каталог WB по точному ШК и повторяет отправку один раз.
- Ошибка теперь показывает warehouseId, ШК и chrtId, чтобы различать ошибку склада от ошибки карточки.

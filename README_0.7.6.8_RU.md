# FulfillCore 0.7.6.8 — палетная приёмка

Добавлен отдельный этап приёмки палет и коробов до появления товара.

## Логика
1. Создаётся палетная приёмка.
2. Сканируется/вводится палета.
3. На выбранную палету сканируются короба. Названия свободные: цифры, буквы, обычные ШК и смешанные значения.
4. Пока Excel не загружен, в этих коробах товара нет.
5. Затем к этой же приёмке загружается Excel: короб | ШК товара | количество | артикул | размер.
6. Товар принимается в конкретные уже принятые короба. Связь палета → короб сохраняется, поэтому видно, на какой палете находится короб с товаром.
7. Остаток сначала меняется только в FulfillCore. На WB FBS он отправляется отдельной кнопкой. Для Ozon локальный остаток и раскладка готовы, но публикация остатка требует однозначной привязки к Ozon offer_id/product_id и не выполняется автоматически по одному ШК.

Повторная загрузка Excel в уже заполненную палетную приёмку блокируется, чтобы случайно не задвоить остатки.

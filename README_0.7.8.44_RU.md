# FulfillCore 0.7.8.44

Накопительное обновление: содержит все изменения версий до `0.7.8.43` включительно. Отдельно устанавливать предыдущие архивы не требуется.

## Что добавлено в 0.7.8.44

- QR-этикетки ячеек и палет отправляются в настроенный Print Agent.
- После массового создания адресов включена автоматическая печать всего нового диапазона. Флажок можно снять перед созданием.
- Ручная приёмка больше не меняет остаток после одного сканирования.
- Сначала формируется черновик: ячейка, товар, артикул, название, размер, ШК и количество.
- В черновике можно изменить количество, убрать отдельную строку или очистить весь список.
- Только кнопка `Добавить всё на остатки` проводит весь проверенный черновик одной операцией.
- Один ШК можно отсканировать один раз и указать любое целое количество штук.
- Если USB-сканер записал один EAN два раза подряд, программа распознаёт задвоение и использует один корректный ШК.
- Название, артикул и размер определяются по точному ШК и локально сохранённой карточке WB.
- Локальный товар, который не попал в каталог WB, больше не скрывается в разделе `Остатки`.
- В карточке ячейки можно удалить ошибочно принятую строку целиком после отдельного подтверждения. Корректировка остаётся в истории.
- Excel- и палетная приёмки также проводят товар только после итоговой кнопки `Добавить всё на остатки`.
- Сканирование ЧЗ относится только к упаковке заказа WB и не проводит складскую приёмку.

## Как работает ручная приёмка

1. Отсканируйте QR ячейки.
2. Отсканируйте ШК товара и нажмите Enter.
3. Укажите количество штук и нажмите Enter.
4. Проверьте появившуюся строку в черновике.
5. Повторите для остальных товаров.
6. При необходимости измените количество или нажмите `Убрать`.
7. Нажмите `Добавить всё на остатки` и подтвердите проведение.

До шага 7 остатки FulfillCore и WB не меняются.

## Исправление уже ошибочно принятого товара

Откройте `Склад → Ячейки / палеты`, затем нужный вид хранения, стеллаж, этаж и ячейку. У строки товара нажмите `Удалить ошибочную строку` и подтвердите действие. Снимается только выбранный локальный остаток; запись остаётся в истории ячейки. Остаток WB автоматически не меняется.

## Печать QR адресов

В `Настройки → Настройки печати` должен быть выбран режим Print Agent и указана станция, например `PACK-01`. Print Agent должен быть запущен на компьютере с принтером.

При массовом создании ячеек или палет флажок `Сразу напечатать созданные QR-этикетки` включён по умолчанию. Повторно можно напечатать одну ячейку, выбранные адреса, диапазон или все адреса склада.

Если оператор вручную выбрал браузерный режим печати, обычные повторные кнопки открывают PDF. Автоматическая печать нового диапазона всё равно отправляется в Print Agent.

## Установка

Распакуйте архив поверх `/opt/fulfillcore`, затем перезапустите контейнер API. Миграция базы данных не требуется. После перезапуска версия API должна быть `0.7.8.44`; на всех рабочих компьютерах нужно нажать `Ctrl+F5`.

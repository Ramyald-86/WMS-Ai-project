# FulfillCore 0.7.8.34 — история остатков, короба и массовые ячейки

## Исправлено

- В журнале операций теперь показываются не только количество и тип «Корректировка», но и результат: сколько было и сколько стало.
- Для перемещения показываются оба изменения: остаток в исходном и конечном адресе.
- Колонка «Кол-во» переименована в «Изменение остатка».
- У пустого короба появилась кнопка удаления. Короб с товаром удалить нельзя до перемещения или списания содержимого.
- У короба появилась кнопка «Переместить»: адрес короба назначается и изменяется именно складской операцией перемещения.
- На странице коробов добавлено пояснение, что короб является отдельным перемещаемым местом хранения.
- Исправлено подключение мастера массовых ячеек к реально отображаемой форме. Старая одиночная форма больше не должна оставаться на экране.

## Массовое создание ячеек

1. Откройте «Склад → Ячейки / палеты».
2. Поле «Проход» можно оставить пустым.
3. Выберите «Стеллаж с ячейками».
4. Укажите номер стеллажа.
5. Укажите этажи «от–до».
6. Укажите номера ячеек «от–до».
7. Нажмите «Создать ячейки».

Пример: этажи 1–6, ячейки 1–23 создадут 138 адресов.

## Установка

### 1. Скачайте архив

`FulfillCore_0.7.8.34_Stock_History_Boxes_Bulk_Locations_FIX.zip`

### 2. Передайте архив на сервер из PowerShell

```powershell
scp "$env:USERPROFILE\Downloads\FulfillCore_0.7.8.34_Stock_History_Boxes_Bulk_Locations_FIX.zip" root@5.129.203.223:/root/
ssh root@5.129.203.223
```

### 3. Установите

```bash
cd /opt/fulfillcore
mkdir -p backup_before_0.7.8.34
cp -a app backup_before_0.7.8.34/
unzip -o /root/FulfillCore_0.7.8.34_Stock_History_Boxes_Bulk_Locations_FIX.zip -d /opt/fulfillcore
```

### 4. Перезапустите API

```bash
docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  restart api
```

### 5. Проверьте версию

```bash
sleep 10
docker compose \
  --env-file server/.env.server \
  -f docker-compose.server.yml \
  -f docker-compose.hotpatch.yml \
  exec api python -c "from app.main import app; print(app.version)"
```

Ожидаемый результат: `0.7.8.34`. После установки нажмите `Ctrl+F5`.

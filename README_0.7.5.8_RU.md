# FulfillCore 0.7.5.8 — Cancelled orders fix

Исправлено:
- отменённые заказы WB больше не остаются в «Новых»;
- статусы supplierStatus/wbStatus применяются сразу из истории/ленты заказов, не ожидая следующего пакетного запроса статусов;
- добавлены варианты cancel/cancelled и carrier/client/seller aliases;
- статусы нормализуются в нижний регистр перед маршрутизацией.

После установки выполнить Ctrl+F5 и один раз «Синхронизировать WB».

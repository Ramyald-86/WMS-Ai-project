# FulfillCore Print Agent

Print Agent ставится **на каждый компьютер упаковщика**, к которому подключён локальный принтер этикеток.

Он сам опрашивает сервер FulfillCore, забирает задания своего рабочего места (`PACK-01`, `PACK-02`...) и отправляет PDF на выбранный Windows-принтер. Поэтому сервер может находиться в интернете/VPS, а принтер остаётся рядом с упаковщиком.

## Что потребуется

1. Установленный драйвер XPrinter и рабочая тестовая печать из Windows.
2. SumatraPDF (нужна для тихой печати PDF без диалога).
3. Скопировать `config.example.json` как `config.json`.
4. В `config.json` указать адрес сервера, код рабочего места и точное имя принтера Windows.
5. Запустить `start_print_agent.bat`.
6. После проверки запустить `install_autostart.bat` — агент будет стартовать вместе с Windows.

В `agent_token` вставьте значение `PRINT_AGENT_TOKEN` с сервера. Логин и пароль сотрудника Print Agent не хранит и не использует.
